## 入口與新建

版型設計提供新建、檔案管理、版型記錄、範本、預設、密度庫和人物檔案。新建先選棒針或鉤針，再選自由繪製、人體原型起稿、策略或範本。自由繪製直接進入空白網格，不必先選人物、策略或密度。策略與範本只是可選起稿，之後進入同一畫布自由修改。檔案管理保留歸屬與資料夾；記錄和資源庫支援長按刪除並確認。

<a id="canvas"></a>
## 畫布與手勢

單指或筆執行當前工具，雙指平移、捏合縮放。選擇對象後再拖動；重疊時長按選擇，或到對象面板指定。繪制→幾何工具提供構造點、兩點或拖動的直線、連續連線、矩形和從圓心拖出的圓。構造點可保存並供端點吸附；開放線可保留、續畫或明確閉合。編輯→節點中選中線段後，拖中點可調整彎度並保持端點；方柄用於精修曲線。畫筆用於草繪與手寫，橡皮只擦草繪。單條草繪可預覽確認轉為獨立衣片，原筆跡保留；連接開放路徑會預覽生成連續副本，原路徑與標注保留。一次連續動作可撤銷。

<a id="tools"></a>
## 底部工具

底部按繪制、編輯、標注、編織、人物與參考、預覽、對象與顯示組織；大類切換顯示簡短提示。常用工具直接顯示，同類動作按需展開，完成、閉合、保留開放線和取消只在當前路徑繪制期間出現。Text、Tips、引線和尺寸在標注中；密度、邊界、編織連接、圖解放置及單片提花在編織中。網格顯示與網格/端點吸附、方向約束分別控制。

繪製工具的目前項目保持醒目顯示。幾何入口顯示目前形狀，例如「幾何：圓」，彈出選單也標記目前項目；開啟或取消選單不切換工具。長按工具可查看用途。輪廓筆直接建立可編輯的衣片輪廓，完成時可閉合成片或保留開放線；畫筆儲存草繪和手寫筆跡，經預覽確認才能轉換為獨立衣片。對稱按鈕獨立顯示開啟狀態，適用於輪廓筆和連續連線。

自動物件選單依完成時機顯示：矩形、圓、橢圓和直線完成後，在畫布外固定工具區顯示快捷操作，保留目前繪製工具；輪廓與連續連線在明確閉合或保留開放線後顯示。取點、拖動及未完成路徑期間不顯示；開始下次繪製時隱藏舊操作並保留工具區高度，避免落筆時畫布跳動。畫筆每筆與橡皮操作後不自動彈出。文字、Tips、圖片、尺寸新增完成後也顯示對應操作。主動選取物件仍使用就近浮動選單；幾何、顏色與吸附選項由工具開啟。

雙擊既有物件是額外快捷編輯入口：空閒的繪製或選取工具中，雙擊衣片進入拉伸、縮放和排版旋轉，雙擊草繪或圖片進入整體變換；Text/Tips編輯內容與樣式，尺寸進入尺寸編輯。原型只選取目前片並提供位置解鎖，不能拉伸。畫布顯示編輯對象與「完成編輯」，完成後返回原選單及繪製工具；直接切換工具則採用新選擇。未完成輪廓、尺寸放置、構造點與兩點直線優先繪製；連續連線已有路徑時雙擊仍為閉合。選取／節點／變換中雙擊空白可適配視圖。鎖定物件須先解鎖。草繪變換保留筆跡，旋轉後轉衣片、擦除、命中及匯出使用相同紙面位置；圖解沿用密度映射。

選取物件後的浮動選單依類型保留常用操作，並提供「物件與圖層」和「更多」。衣片可變換、編輯節點及複製；文字/Tips可編輯內容與樣式；草繪可預覽轉衣片；尺寸可直接編輯。物件面板開啟時定位並反白目前物件，每列右側「更多」提供該物件的編輯、重新命名、複製、層序和刪除等可用操作，始終作用於該列。鎖定物件須先解鎖才能編輯或刪除。人體原型與人體參考可複製其中一片為獨立衣片；「隱藏參考」只控制顯示，保留人體來源。刪除衣片會移除相關連接，保留文字、人工尺寸和圖解記錄並提示關聯失效；已有獨立圖解和其他作品保留。複製、刪除和層序操作可在本次編輯中復原，刪除前會確認。

幾何工具支援橢圓：按住拖動，以外接矩形的對角決定寬高。選取衣片後進入編輯→變換，拖邊緣控制點橫向或縱向拉伸，拖角落控制點等比縮放；開啟鎖定比例後邊緣控制點也保持比例。頂部控制點只旋轉圖紙上的排版，精確尺寸可輸入公分寬高與排版角度，重設角度保留中心和實際尺寸。拉伸與縮放修改實際輪廓，有密度時重新估算針行，手動方案保留並提示複核；排版旋轉不改編織方向或針行方案。文字與尺寸隨錨點移動並保持可讀，圖解隨衣片排版旋轉，人體原型對照繼續使用實際尺寸和原編織方向。雙指捏合只縮放視圖；節點與曲線仍可精修。變換可復原，儲存後恢復排版角度及比例鎖狀態。

人體原型的前身、後身和袖部，以及人體尺寸參考的各片，分別顯示於物件與圖層，可單獨選取、解鎖、移動、隱藏和排序。點按原型輪廓、參考線或標題選取該片，解鎖後可在選取框內拖動；該片的結構線、點及說明一起移動，其他片保持原位。舊作品各片繼承先前整組的位置、顯隱及鎖定狀態。更新人體資料時保留對應部件身分和已調整位置。原型維持1:1，唯讀輪廓不提供拉伸或節點編輯；「複製為衣片」直接複製目前片，副本可自由修改。位置可復原並隨作品儲存，精確檢查仍使用原型對照頁。

<a id="context"></a>
## 版片快捷操作

在標註→關聯尺寸中選擇上、下、左、右或直線標註，連續點擊節點或衣片範圍基準建立分段。公分測量與針行估算分開顯示，可另存自己的計畫數量。四側標籤自動錯開，也可拖動整理；拖標籤不改衣片。物件檢查器的邊界可新增弧長標註，弧長不直接換算針數。標註提供多行 Text、點擊展開的 Tips、引線、參考圖等；文字可調字級和對齊。可關聯最近輪廓節點，隨節點移動且仍可單獨拖動；錨點刪除後顯示失效，不會改綁其他節點。

<a id="counts"></a>
## 尺寸與針行方案

估算讀取目前真實輪廓的寬高、周長、面積和逐行覆蓋，支援四種編織方向；不會重跑策略覆蓋手工路徑。缺密度時仍可畫圖和看公分。有密度的幾何估算也不等於已確認編織方案；開放、自交或其他不能計算的輪廓會提示檢查。頂部方案可編輯起針、總行、兩側、領口和中央留針等適用項目。改形、密度或方向後保留人工步驟與計畫數量，標記需複核。

<a id="settings"></a>
## 模板、人物與通用設定

人物與參考中可選擇人物、補充測量、添加參考圖片或從正式原型複製獨立衣片。換人物不修改已畫輪廓。對象與顯示→對象與圖層支持選擇定位、顯隱、鎖定、拖動排序及置頂置底；鎖定對象不參與普通拖動，仍可從面板選擇解鎖。圖紙與顯示可選深色、淺色或自定義背景、釐米主細網格、針行網格及參考樣式；不會重染已有衣片或文字。更多→新建默認設置僅影響後續新作品，當前作品可明確使用通用圖紙默認值。

<a id="membership"></a>
## 免費版與會員

免費版最多同時保留 2 個版型，刪除版型會釋放名額；達到上限後，已有版型仍可繼續打開、編輯、保存和刪除。自由繪制、人體尺寸參考、正式人體原型、松分、Gauge、尺寸、曲線、節點和針行方案等基礎製版能力不會被鎖定。

基礎落肩長袖套頭衫是免費策略。合體裝袖及後續高級策略、我的模板、多套常用預設、自定義策略和策略包導入導出需要會員。“生成準備”可免費檢查缺失資訊；真正點擊創建棒針圖解時才檢查會員，後續計數器任務、鉤針圖解和毛線估算也遵守同一規則。

<a id="evidence"></a>
## 證據狀態與後續聯動

生成與聯動提供棒針圖解、平面片鉤圖解、計數器和毛線估算。生成準備逐項顯示資料，可直達密度、方案或原畫布補全；從畫布再進入會繼續原準備任務。正式圖解需可執行且確認的方案，幾何估算本身不能直接發佈。自由閉合衣片也可用於平面片鉤，仍受針法與拓撲能力限制。計數器儲存可追溯任務；用量依有效閉合面積和實測樣片估算，任一衣片面積無效需先修復，不用外接矩形代算，也不自動扣庫存。

<a id="workflow-save-export"></a>
## 預覽、匯出與儲存

預覽中的平面試穿顯示實際衣片與人體參考，返回保留畫布現場。更多→導出設計圖可獨立選擇網格和Tips展開、編號附錄或隱藏。保存保留開放輪廓、結構化標注、對象順序及圖紙；每份作品獨立恢復視口、工具、選擇和已確認的比較現場，不重放命令或恢復撤銷棧。版型記錄與文件列表共用最近成功保存的完整設計預覽，不把最後放大局部或空白視口當封面。已有可讀作品保留身份、幾何、標注與計劃；無法識別的記錄不被空白內容覆寫。本輪未編譯、未真機驗收。

<a id="body-block-comparison"></a>
## 原型對照

預覽→原型對照從當前衣片進入。選擇對應前身或後身原型、整片或半片，在衣片上標記中線與胸/腰等對應高度，再選擇高度對齊並鎖定參考；比例始終為1:1。單指只移動解鎖的參考，雙指導航。按需標記同側領肩、肩端、領中心、腋下和下擺，查看實際輪廓的片寬、左右平面差、肩領與縱向距離；多區間或缺少標記時不報單一寬度。點結果可高亮，確認後保存比較依據和位置，返回畫布改形後可繼續同一對照；取消不提交。原型含製圖規則與推算，差值不等於整衣松量、體表間隙、壓力或合體結論。

<a id="try-on-3d"></a>
## 3D 靜態預覽

從預覽→3D靜態預覽進入，二級工具為人物、裝配、試穿、顯示、視角、調整。單指旋轉、雙指平移、捏合縮放；切回其他工作大類後繼續二維編輯。已有靜態3D能力與限制保持。

寬厚比例、頭部及四肢含範本估算，後肩寬及體表長度尚未擬合。缺少身高時請補錄，或明確選擇165 cm參考身高。尺寸與回量顯示來源、網格截面圍度及輪廓誤差。版片或連接變更後，舊結果標記待更新；產生可取消。

這是靜態網格預覽，尚未驗證布料伸縮、彎曲、人體碰撞或合體，不提供壓力或合體評分。本輪尚未編譯或通過實機驗收。

若先前出現「人體網格未閉合或方向異常」，更新後請重新進入人物詳情並重新生成；無需刪除人物或重新輸入測量資料。此修復尚待真機驗收。

<a id="piece-colorwork"></a>
## 單片提花

從「編織 → 單片提花」或「3D → 顯示 → 單片提花」進入，選擇前片、後片或其他目標片，再選擇已有棒針顏色圖解。預設按針密和行密從底部置中重複鋪滿；可改為單個花樣、按整數針／行偏移、調整底色及逐一替換花樣顏色。畫布也可整針整行拖曳，領口、袖窿與片外區域自動裁切；每格仍代表一針一行，不拉伸湊滿。單個花樣範圍外及來源空白／透明顏色格均用所選底色。

儲存或刪除可復原，取消不會提交。源圖解或密度變更後需同步；若儲存時又發現變更，先更新預覽，確認後再次儲存。二維、裝配、三維及可執行棒針輸出共用取色規則，左右起針只改變編號；提花只染有效針格，保留預設及下層圖解針法。首版只接受顏色格或普通上下針，顯式空針、跨格及其他結構針法、半透明色不能作為來源。暫不提供跨縫自動對花、花帶、配色收藏、真實浮線及布料模擬。
