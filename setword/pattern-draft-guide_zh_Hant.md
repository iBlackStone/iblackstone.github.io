## 入口與新建

版型設計首頁提供新建版型、文件管理、版型記錄、我的模板、常用預設、Gauge 庫、人物檔案和版型通用設定。新建時先選擇棒針或鉤針，再選擇自由繪制、策略生成或我的模板；三種方式都會生成同一種版型專案並進入同一個編輯器。“文件管理”是推薦的查找和整理入口，“版型記錄”保留傳統列表；從作品關聯已有版型時使用文件選擇頁。通用設定只影響以後新建的預設值；編輯器中的“當前版型設定”才修改當前專案。

自由繪制從 FlatPiece、Tube 或 FreeformPiece 開始。策略生成適合快速得到完整初稿；當前內置基礎背心、落肩長袖、合體裝袖、插肩、開衫、圓形育克、方形育克和斜編。人體原型會按松分與結構修正推導成衣尺寸並保留計算來源；插肩/育克的完整加減針節奏、斜編方向密度、裝袖松量和挑針仍會顯示為“需要確認”或“暫時不能自動完成”。模板會複製版片、邊界、關係和顯示設定，但不複製人物身份或測量快照。

<a id="canvas"></a>
## 畫布與手勢

編輯器固定使用黑色工作區和釐米數學坐標。單指拖動空白區域平移，雙指捏合縮放，雙擊或“適合”讓內容回到可視區域。輪廓、網格、標注和針行階梯都按數學坐標重繪，放大不會依賴低清位圖。

選擇人物後，青色虛線“人體尺寸參考”用於比較人體寬度、成衣寬度與松分；金色“人體原型”則按製圖規則顯示前後身、袖片、領口、肩線、袖窿、袖山、胸腰臀線、胸點和對應釐米資料。它們與最終成衣版片是三層獨立內容，可在“圖層”中分別顯示或隱藏；關閉“成衣版片”可單獨檢查原型。缺少測量或未確認的成衣變換仍保持候選/unknown，不會補畫猜測結果。

點擊版片將其選中。開啓節點編輯後，先點擊節點使它變成橙色。直線/曲線用於切換該節點前面的輪廓段；曲線會顯示兩個方形 Bezier 控制柄。角點允許兩側獨立轉折，平滑會對齊兩側曲線方向；還可以開閉輪廓或刪除非起始節點。鎖定的版片不會被誤改。

<a id="tools"></a>
## 底部工具

底部保持兩排：下排是選擇、新增、幾何、結構、尺寸、版片和圖層七個工作模式；當前模式會用橙色選中框標出，上排隨之顯示具體動作。長按任意工具可查看面向初學者的完整說明。

畫布左上角的方案卡預設收成一行，保留當前組件、起針、總行數和候選狀態；缺少密度或存在警告時仍會顯示提示。點擊卡片可展開或收起，選擇會自動記住。完整針行詳情仍從頂部“方案”進入。

在輔助工具中選擇“放置棒針圖解”，可把已有圖解按當前 Gauge 換算後放入所選版片。圖解會裁切在版片輪廓內並可拖動；源圖解或 Gauge 變化時，檢查器會提示同步。

- 新增：平面、筒狀、帶狀和自由版片保持常駐；低頻的文字、資訊點、參考圖片、參考線、手動尺寸、引線說明和圖解位置收在“輔助”向上工具板中。參考圖片可從拍照、文件或相冊選擇。
- 幾何：節點、加點和精確寬高保持常駐；直線/曲線、角點/平滑、開閉輪廓/刪除節點分別收進“線段”“點類型”“輪廓”工具板。鏡像統一放在“版片”模式，避免重復按鈕。
- 向上工具板中的按鈕也支援長按說明；點擊畫布空白處可關閉工具板。
- 結構：Boundary 語義、Join 和 Split。
- 尺寸：當前版型設定、尺寸、候選階梯和 `2-1-3` 簡寫。
- 圖層：人體尺寸參考、正式人體原型、成衣版片、釐米格、針行格、尺寸、階梯、簡寫和輔助組件顯示。

<a id="context"></a>
## 版片快捷操作

選中版片後，附近會顯示小型快捷工具條。工具條優先位於組件頂部外側並保持 16pt 間距，頂部空間不足時會自動移到下方。統一對象檢查器集中查看名稱、位置、尺寸、顏色、層級、鎖定、Boundary、Feature、Relation、輔助組件和手動尺寸；輔助組件也可以複製或刪除。Boundary 可以標記為起針、收針、活針、縫合、挑針、折疊或開口；版片之間可建立 Join、Split、Mirror 等關係。

<a id="counts"></a>
## 尺寸與針行方案

“尺寸”顯示版片總寬高以及領寬、領深、肩寬、肩斜、袖窿等可用區域尺寸。填寫實際試片的橫向針密和縱向行密後，編輯器才會生成針數、行數和候選加減針方案。

右上角“方案”可隨時打開當前版片的完整方案。方案頁同時保留逐行操作和日式簡寫，例如 `2-1-3` 表示按指定行間隔、每次針數和重復次數執行。修改簡寫會反向重建對應逐行步驟並標記為用戶編輯。

方案內容會按當前組件類型顯示：前後片才顯示袖窿、領口、中心留針和肩部；袖片顯示袖片收放；帶狀、筒狀及自由組件只顯示自身的起針、總行數和兩側加減針，不會套用毛衣衣身字段。

<a id="settings"></a>
## 模板、人物與通用設定

人物檔案保存可重復使用的測量記錄。首次使用會提供可刪除的“女性參考 · XS/S/M/L/XL”五個快速起點，也可選擇成人女性、成人男性或兒童/青少年公開標準快速填寫，再逐項改成真實測量值。後肩寬、胸點間距/下落、肘圍和袖長會用於正式原型；每個字段分別記錄來源，專案保存創建時的數值與來源快照，人物以後變化不會靜默改寫舊版型。Gauge 庫保存常用試片密度。

“人體尺寸、松分與結構修正”可分別設定胸圍、腰圍、臀圍、上臂和手腕松分，以及肩線上抬、肩寬延伸、袖窿深修正等結構參數。松分表示成衣與身體之間的空間，結構修正表示製圖線的位置變化，兩者不會混成一個數值。版型通用設定可分別決定新專案是否顯示人體尺寸參考和正式人體原型。

右上角“更多”按“當前版型、畫布與幫助、高級資訊”分組，並在最後提供刪除當前版型。高級資訊中的“查看生成方式”和“查看計算依據”只用於瞭解版型來源與計算狀態，日常繪制不需要操作。

<a id="membership"></a>
## 免費版與會員

免費版最多同時保留 2 個版型，刪除版型會釋放名額；達到上限後，已有版型仍可繼續打開、編輯、保存和刪除。自由繪制、人體尺寸參考、正式人體原型、松分、Gauge、尺寸、曲線、節點和針行方案等基礎製版能力不會被鎖定。

基礎落肩長袖套頭衫是免費策略。合體裝袖及後續高級策略、我的模板、多套常用預設、自定義策略和策略包導入導出需要會員。“生成準備”可免費檢查缺失資訊；真正點擊創建棒針圖解時才檢查會員，後續計數器任務、鉤針圖解和毛線估算也遵守同一規則。

<a id="evidence"></a>
## 證據狀態與後續聯動

`confirmed` 表示有明確依據，`candidate` 表示需要人工審核，`unknown` 表示現有知識不足。自由幾何不會因為 unknown 被阻止，但系統不會為了給出完整答案而虛構算法。

點擊“生成與聯動”可選擇計數器任務、棒針圖解、鉤針圖解或毛線用量估算。每項都會先進入“生成準備”，顯示來源版型、歸屬作品和完整度檢查。若從作品內進入版型，會自動繼承該作品；獨立進入時可以選擇目標作品。綠色專案可直接使用，橙色仍需確認，紅色必須補齊。

棒針圖解目前已打通單版片路徑：點擊“圖解針法”選擇前片、後片或袖片，設定往返/圈織、第一行正反面、起始方向和正反面針法，然後查看邏輯針格預覽。若方案尚未確認，可直接點擊準備檢查中的“針行方案”編輯並確認當前版片。候選方案只能預覽；確認後點擊“創建並打開棒針圖解”會生成可繼續編輯的圖解，並把它關聯到上方選擇的大作品。

鉤針圖解也已打通單個平面版片的往返片鉤路徑。在“鉤針圖解設定”中選擇版片、主體針法、第一行方向、起立針數量及其是否計入針數，再進入診斷預覽。系統會把版型中的邊緣加減針和中心開口解釋成逐行連接拓撲，並明確顯示斷線、懸空連接、針數不守恆和規模警告。`candidate` / `unknown` 可以進入診斷預覽，但發佈前必須確認方案並解決 `unknown`。創建後會得到可繼續編輯的獨立鉤針圖解文件並關聯到目標作品；源版型變化後關聯會標記為已過期，重新生成會創建新文件，解除關聯不會刪除已有圖解。V1 暫不生成筒狀圈鉤、螺旋鉤、高級組合針或整件多版片圖解。

毛線用量也已打通首個可用路徑。請準備一塊與作品針法、密度相同的實際試片，填寫寬度、高度和稱得的重量；如知道試片耗線米數也可填寫。系統會按版片輪廓計算基礎用量，並預設增加 10% 作為接線、縫合、收尾和少量誤差的預留。選擇庫存毛線後還會帶入單團規格、顯示建議團數和庫存差額；不選擇庫存毛線也能估算總克數。結果保存在作品“使用毛線資訊”的“用量計劃”，同時可從“專案資源”追溯。估算不會自動寫成實際消耗，也不會扣減庫存。計數器仍只保存準備方案。

放入版片的已有棒針圖解可在檢查器中選擇“自動繪制”或“只作參考”。自動繪制要求圖解已同步並保持 1:1；生成時，圖解中的有效針格會覆蓋該版片的預設針法。需要讓花樣延續到相鄰版片時，先在“結構”中依次選擇兩塊版片的具體連接邊，再選擇“跨接縫連續”。“裝配”可預覽縫合後的相對位置和邊長匹配狀態；只有顯示為邊長匹配的連接才會自動延續花樣，待確認或缺少邊界的連接不會被強制計算。
