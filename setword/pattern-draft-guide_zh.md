## 入口与新建

版型设计提供新建、文件管理、版型记录、模板、预设、密度库和人物档案。新建先选棒针或钩针，再选自由绘制、人体原型起稿、策略或模板。自由绘制直接进入空白网格，不要求先选人物、策略或密度。策略和模板只是可选起稿，之后进入同一画布自由修改。文件管理保留归属与文件夹；记录和资源库支持长按删除并确认。每次“自由绘制”都会新建空白文档；此前未动过的空白草稿会在下次新建时清理，空草稿不占免费额度。

<a id="canvas"></a>
## 画布与手势

单指或笔执行当前工具，双指平移、捏合缩放。选择对象后再拖动；重叠时长按选择，或到对象面板指定。绘制→几何工具提供构造点、两点或拖动的直线、连续连线、矩形和从圆心拖出的圆。构造点可保存并供端点吸附；开放线可保留、续画或明确闭合。编辑→节点中选中线段后，拖中点可调整弯度并保持端点；方柄用于精修曲线。画笔用于草绘与手写，橡皮只擦草绘。单条草绘可预览确认转为独立衣片，原笔迹保留；连接开放路径会预览生成连续副本，原路径与标注保留。一次连续动作可撤销。

<a id="tools"></a>
## 底部工具

绘制→吸附中，网格吸附使用当前可见的厘米刻度，缩放时同步调整。端点与参考线吸附包括衣片、图片、草绘的边缘/中线、辅助参考线及已显示原型的中线、胸腰线等；锁定目标仍可参考，隐藏目标不参与。橙色圆点与虚线表示命中，拖离即解除。文字按中心、Tips和引线按位置吸附；画笔、曲线柄与尺寸标签保持自由。人物、原型对照、图纸及对象属性的选项菜单对准实际点击的行。

底部按绘制、编辑、标注、编织、人物与参考、预览、对象与显示组织；大类切换显示简短提示。常用工具直接显示，同类动作按需展开，完成、闭合、保留开放线和取消只在当前路径绘制期间出现。Text、Tips、引线和尺寸在标注中；密度、边界、编织连接、图解放置及单片提花在编织中。网格显示与网格/端点吸附、方向约束分别控制。编辑模式保留变换、属性、节点、线段、点类型、轮廓和“更多编辑”；加点、连接路径、精确、复制、镜像、锁定、删除等低频动作收在“更多编辑”中。

绘制工具的当前项保持高亮。几何入口显示当前形状，例如“几何：圆”，弹出菜单也标记当前项；打开或取消菜单不切换工具。长按工具可查看用途。轮廓笔直接创建可编辑的衣片轮廓，完成时可闭合成片或保留开放线；画笔保存草绘和手写笔迹，经预览确认才能转换为独立衣片。对称按钮单独显示开启状态，适用于轮廓笔和连续连线。

自动对象菜单按完成时机显示：矩形、圆、椭圆和直线完成后，在画布外的固定工具区显示快捷操作，并保留当前绘制工具；轮廓和连续连线在明确闭合或保留开放线后显示。取点、拖动及未完成路径期间不显示；开始下一次绘制时隐藏旧操作，保留工具区高度，避免落笔时画布跳动。画笔每笔和橡皮操作后不自动弹出。新增文字、Tips、图片、尺寸完成后也显示对应操作。主动选择对象仍使用就近浮动菜单；几何、颜色与吸附选项由点击工具打开。

双击已有对象是额外的快捷编辑入口：空闲的绘制工具或选择工具中，双击衣片进入拉伸、缩放和排版旋转，双击草绘或图片进入整体变换；Text/Tips编辑内容和样式，尺寸进入尺寸编辑。原型只选中当前片并提供位置解锁，不能拉伸。画布显示正在编辑的对象与“完成编辑”，完成后返回原菜单和绘制工具；直接切换工具则采用新选择。未完成轮廓、尺寸放置、构造点和两点直线优先处理绘制；连续连线已有路径时双击仍为闭合。选择/节点/变换模式下双击空白可适配视图。锁定对象需先解锁。草绘变换保留笔迹，旋转后转衣片、擦除、命中和导出使用同一纸面位置；图解仍走原有密度映射。

选中对象后的浮动菜单按类型保留常用操作，并提供“对象与图层”和“更多”。衣片可变换、编辑节点和复制；文字/Tips可编辑内容与样式；草绘可预览转衣片；尺寸可直接编辑。对象面板打开时定位并高亮当前对象，每行右侧“更多”提供该对象的编辑、重命名、复制、层序和删除等可用操作，始终作用于该行。锁定对象需先解锁才能编辑或删除。人体原型与人体参考可复制其中一片为独立衣片；“隐藏参考”只控制显示，保留人体来源。删除衣片会移除相关连接，保留文字、人工尺寸和图解记录并提示关联失效；已有独立图解和其他作品保留。复制、删除和层序操作可在本次编辑中撤销，删除前有确认。

几何工具支持椭圆：按住拖动，用外接矩形的对角确定宽高。选中衣片后进入编辑→变换，拖边柄横向或纵向拉伸，拖角柄等比缩放；开启锁定比例后边柄也保持比例。顶部手柄只旋转图纸上的排版，精确尺寸可输入厘米宽高与排版角度，复位角度保留中心和实际尺寸。拉伸与缩放修改真实轮廓，有密度时重新估算针行，手动方案保留并提示复核；排版旋转不改编织方向或针行方案。文字与尺寸随锚点移动并保持可读，图解随衣片排版旋转，人体原型对照继续使用实际尺寸和原编织方向。双指捏合只缩放视图；节点与曲线仍可精修。变换可撤销，保存后恢复排版角度及比例锁状态。

人体原型的前身、后身和袖部，以及人体尺寸参考的各片，分别显示在对象与图层中，可单独选择、解锁、移动、隐藏和排序。点击原型轮廓、参考线或标题选中该片，解锁后可在选框内拖动；该片的结构线、点和说明一起移动，其他片保持原位。旧作品各片继承此前整组的位置、显隐和锁定状态。更新人体资料时保留对应部件身份及已调整的位置。原型始终保持1:1，只读轮廓不提供拉伸或节点编辑；“复制为衣片”直接复制当前片，副本可自由修改。位置可撤销并随作品保存，精确检查仍使用原型对照页。

<a id="context"></a>
## 版片快捷操作

在标注→关联尺寸中选择上、下、左、右或直线标注，连续点击节点或衣片范围基准建立分段。厘米测量与针行估算分开显示，可另存自己的计划数量。四侧标签自动错开，也可拖动整理；拖标签不改衣片。对象检查器的边界可添加弧长标注，弧长不直接换算针数。标注提供多行 Text、点击展开的 Tips、引线、参考图等；文字可调字号和对齐。在检查器可关联最近轮廓节点，标注随节点移动且仍可单独拖动；锚点删除后显示失效，不会改绑其他节点。

<a id="counts"></a>
## 尺寸与针行方案

估算读取当前真实轮廓的宽高、周长、面积和逐行覆盖，并支持四种编织方向；不再通过重跑策略覆盖手工路径。缺密度时仍可画图和看厘米。有密度的几何估算也不等于已确认的编织方案；开放、自交或其他不能计算的轮廓会提示检查。顶部方案中可编辑起针、总行、两侧、领口和中心留针等适用项目。改形、改密度或方向后保留人工步骤与计划数量，标记需要复核。罗纹下摆和袖口会单独列出罗纹行，收放针从罗纹后开始；落肩策略不要求目标肩宽，改为显示由肩宽、袖窿深和落肩量推算的落肩量。

<a id="settings"></a>
## 模板、人物与通用设置

人物与参考中可选择人物、补充测量、添加参考图片或从正式原型复制独立衣片。换人物不修改已画轮廓。对象与显示→对象与图层支持选择定位、显隐、锁定、拖动排序及置顶置底；锁定对象不参与普通拖动，仍可从面板选择解锁。图纸与显示可选深色、浅色或自定义背景、厘米主细网格、针行网格及参考样式；不会重染已有衣片或文字。更多→新建默认设置仅影响后续新作品，当前作品可明确使用通用图纸默认值。

<a id="membership"></a>
## 免费版与会员

免费版最多同时保留 2 个版型（没有衣片、标注或尺寸的空草稿不占名额），删除版型会释放名额；达到上限后，已有版型仍可继续打开、编辑、保存和删除。自由绘制、人体尺寸参考、正式人体原型、松分、Gauge、尺寸、曲线、节点和针行方案等基础制版能力不会被锁定。

内置策略在 Beta 期全部免费，包括基础背心、基础落肩长袖套头衫和空白自定义衣片。插肩、开衫、圆育克、方育克、合体装袖和斜编等候选策略暂未开放；已有项目仍可打开和编辑，但不能从目录新建。本机/导入策略可单独解锁，也可通过有效会员使用；我的模板及作者工具仍需要会员。生成准备免费；正式创建图解或计数器时检查会员权益。导出设计图和工艺单 PDF 当前免费。多套预设和策略包导入导出仍属于会员能力。

<a id="evidence"></a>
## 证据状态与后续联动

生成与联动提供棒针图解、平面片钩图解、计数器和毛线估算，以及导出设计图、导出工艺单（PDF）。正式创建输出前会显示“可直接创建”“需确认”或“暂不能创建”：需确认时说明尚未确认的结构，暂不能创建时给出阻断原因。生成准备逐项显示所需资料，可直达密度、方案或原画布补全；从画布再次进入会继续原准备任务。正式图解需要可执行且确认的方案，几何估算本身不能直接发布。自由闭合衣片也可用于平面片钩，仍受针法与拓扑能力限制。计数器保存可追溯任务；用量按有效闭合面积和实测样片估算，任一衣片面积无效时需先修复，不用外接矩形代算，也不会自动扣库存。

<a id="workflow-save-export"></a>
## 预览、导出与保存

更多→导出设计图可独立选择网格和Tips展开、编号附录或隐藏。保存保留开放轮廓、结构化标注、对象顺序及图纸；每份作品独立恢复视口、工具、选择和已确认的比较现场，不重放命令或恢复撤销栈。版型记录与文件列表共用最近成功保存的完整设计预览，不把最后放大局部或空白视口当封面。已有可读作品保留身份、几何、标注与计划；无法识别的记录不被空白内容覆写。

<a id="body-block-comparison"></a>
## 原型对照

预览→原型对照从当前衣片进入。选择对应前身或后身原型、整片或半片，在衣片上标记中线与胸/腰等对应高度，再选择高度对齐并锁定参考；比例始终为1:1。单指只移动解锁的参考，双指导航。按需标记同侧领肩、肩端、领中心、腋下和下摆，查看实际轮廓的片宽、左右平面差、肩领与纵向距离；多区间或缺少标记时不报单一宽度。点结果可高亮，确认后保存比较依据和位置，返回画布改形后可继续同一对照；取消不提交。原型含制图规则与推算，差值不等于整衣松量、体表间隙、压力或合体结论。

<a id="try-on-3d"></a>
## 3D试样与参考材料模拟

正式版点击「预览 → 3D试样」时会显示「3D预览维护升级中，敬请期待」。 以下 3D 操作适用于 Debug 版。

打开“预览 → 3D试样”或切换到3D任务，可使用人物、装配、垂落、显示、视角和调整。所有人体原型、二维尺寸对照和连接检查继续可用。人体根据保存的测量快照生成；在人物录入中可选中性、女性、男性或儿童模板。缺少的形态由模板估算，肩点宽度为定位代理，体表长度等未拟合尺寸保留说明。更换试穿人物不改变衣片。

单片有效闭合轮廓无需先设置密度、衣片角色或接缝，未缝合也可试样。在“装配 → 衣片摆放与固定”中选择衣片，放到胸前、背后或搭在左肩、右肩，再用单指拖动，双指观察。可固定上沿两点、点按添加或解除固定、旋转90°及重置。基础背心可确认肩部和侧边共四组连接，领口、袖窿和下摆保持开口。

“装配 → 参考针织材料”提供柔软垂坠、常规针织和较挺括。这些是参考预设；密度只决定尺寸和花型尺度，不等于弹性。主按钮开始重力垂落，运行时暂停，暂停后继续模拟；也可从初始摆放重新垂落。人体和材料的估算不提供精确合身或压力结论，也不保证所有碰撞都无穿透。

普通观察时，单指水平转台，双指平移或捏合缩放，双击聚焦；可在显示中隐藏底座。保存后，再次打开会恢复试穿配置与相机。

修改真实二维路径后需更新3D。在相同人体、材料、摆放和固定条件下，可用同一视角对比修改前后结果。仅当前有效完成结果可保存效果图；运行中、暂停或已过期的结果不能作为当前结果导出。

复制人体原型得到的前身、后身和袖片，以及显式回到起点再闭合的轮廓，均可进入3D。若某片轮廓或边界无效，衣物试穿暂停，当前人体仍会显示，并提示衣片名称及原因；修正后更新3D。此时不能将人体预览导出为有效的衣物试穿结果。

有效的3D预览可随作品保存；重新打开且版型、人体及模拟条件一致时，可恢复已保存的结果。修改输入后需要重新计算，失败或未完成的结果不会覆盖上次保存的有效预览。

<a id="piece-colorwork"></a>
## 单片提花

从“编织 → 单片提花”或“3D → 显示 → 单片提花”进入，选择前片、后片或其他目标片，再选择已有棒针颜色图解。默认按针密和行密从底部居中重复铺满；可改为单个花样、按整数针/行偏移、调整底色和逐一替换花样颜色。画布也可整针整行拖动，领口、袖窿与片外区域自动裁切；每个花样格仍代表一针一行，不拉伸凑满。单个花样范围外和来源空白/透明颜色格均用所选底色。

保存或删除可撤销，取消不会提交。源图解或密度变化后需同步；若保存时又发现变化，会先刷新预览，确认后再次保存。二维、装配、三维和可执行棒针输出共享取色规则，左右起针只改变编号；提花只染有效针格，保留默认及下层图解针法。首版只接受颜色格或普通上下针，显式空针、跨格和其他结构针法、半透明色不能作为提花来源。 提花呈现颜色外观，尚未模拟浮线或真实组织的材料物性。整体布面垂落使用独立参考材料，不从提花推导真实物性。自动接缝对花、边条和保存配色方案仍不包含。

开发版内部样板：重新构建 Debug App 后，在「新建版型→棒针→策略生成」列表底部打开「Bernat M · 四主片工程对照」。固定 M 码可编辑、保存和重开；不是自动放码策略，领边及罗纹仍待完善，已接入合成参考人体的实验试穿；最终质量和结果保存仍在验收中。
