## 參考價值

資料參考說明
資料僅為參考。因為編織者手勁鬆緊、編織花樣差異，哪怕用同款毛線和針號，織出的小樣密度也會不同。所以手工編織時，通常要先織出小樣並經水洗定型後，再測量實際密度，以此來確定最終作品的針數和行數，避免成品尺寸偏差。

### 一、核心目標
從編程角度實現「基於網格的棒針/鉤針小樣模擬器」，核心是**將毛線物理參數映射為網格的可視化參數，每針映射為一個表格**。

#### 核心技術鏈路
```
輸入參數（線徑/支數/股數等）→ 計算標準編織密度（針數/行數/10cm）→ 換算10cm小樣的網格行列數 → 適配棒針/鉤針工藝的網格樣式 → App端渲染網格
```


### 二、基礎資料標準

所有計算公式均基於以下國際/行業標準，確保資料準確性.


| 標準編號                | 標準名稱                          | 核心應用場景                     |
| :---------------------- | :-------------------------------- | :------------------------------- |
| ISO 2314:2010           | 紡織品 紗線支數的測定             | 支數與線徑、長度的換算           |
| ASTM D2253-19          | 針織物單位面積重量和密度的測試方法 | 編織密度（針數/行數）的計算基準  |
| JIS L1096:2010          | 機織物及針織物的試驗方法          | 棒針/鉤針密度的行業參考範圍      |
| 國際羊毛局（IWTO）標準  | 羊毛紗線線徑與股數的對應關係      | 股數對實際線徑的修正             |

### 三、編織密度計算（ASTM D2253標準）


編織密度（針數/10cm）是網格映射的核心，需結合「實際線徑+工藝類型」計算，參考JIS L1096的密度區間.


| 實際線徑（mm） | 棒針密度（針數/10cm） | 鉤針密度（針數/10cm） | 棒針行數/10cm | 鉤針行數/10cm |
| :------------- | :-------------------- | :-------------------- | :------------ | :------------ |
| 0.2~0.3        | 27~32（細絨線）| 25~30                 | 23~26         | 18~21         |
| 0.3~0.5        | 21~26（中細線）| 20~25                 | 19~22         | 15~18         |
| 0.5~0.8        | 16~20（中粗線）| 15~20                 | 15~18         | 12~15         |
| 0.8~1.2        | 12~15（粗線）| 10~15                 | 11~14         | 8~11          |
| >1.2           | 7~11（超粗線）| 7~10                  | 7~10          | 5~8           |

**示例**：實際線徑0.25mm（2股細絨線）→ 棒針密度=29針/10cm → 棒針行數=29×0.8=23.2行/10cm

#### 1. 核心定義
編織密度 = 規定尺寸（10cm）內的 **橫向針數（Width Gauge）** / **縱向行數（Height Gauge）**  
- 橫向針數：10cm 寬度內的編織針數（決定作品寬度尺寸）；  
- 縱向行數：10cm 高度內的編織行數（決定作品長度尺寸）。

#### 2. 標準測試步驟
ASTM D2253 要求通過「小樣編織+標準化測量」確保準確性，步驟如下：
1. **編織小樣（Swatch）**：  
   - 用實際專案的線線+織針，編織至少 15cm×15cm 的小樣（避免邊緣變形影響測量）；  
   - 編織圖案需與成品一致（平針、元寶針等不同針法密度差異極大）。
2. **蒸汽定型（關鍵步驟）**：  
   - 按線線材質（羊毛/棉/化纖）進行蒸汽熨燙（僅熏蒸，不按壓拉扯）；  
   - 自然晾乾後再測量（未定型的小樣會收縮，導致密度計算偏差）。
3. **精准測量**：  
   - 橫向：在小樣中心區域（避開邊緣 2-3cm）測量 10cm，數清包含的針數（不足 1 針按小數計算，如 18.5 針）；  
   - 縱向：同樣在中心區域測量 10cm，數清包含的行數；  
   - 重復測量 2-3 次，取平均值（提升準確性）。
4. **計算結果**：  
   示例：10cm 內橫向 18 針、縱向 24 行 → 編織密度為「18 針 × 24 行 / 10cm」。

### 四、 棒針與鉤針


用“短/中/長”統一標識二級針法分類


| 通用針法等級 | 棒針映射關係       | 鉤針映射關係       | 核心密度特徵       | 修正系數 |
|:--------------|:--------------------|:--------------------|:--------------------|:--------------|
| 短（Short）  | 平針（Stockinette） | 短針（SC）| 最緊湊（基準）| 1.0          |
| 中（Medium） | 反針（Reverse）| 中長針（HDC）| 中等鬆散           | 0.85         |
| 長（Long）   | 元寶針（Brioche）| 長針（DC）| 極鬆散             | 0.7          |
