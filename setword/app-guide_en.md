## Getting started

1. Open the built-in tutorial project on Home to see how projects, counters, charts, and notes work together.
2. Add yarn records with photos, specifications, stock, and price information.
3. Create a project and attach the yarn you plan to use.
4. Add counters and link knitting charts, crochet charts, or Project Notes.
5. Return to the current-project card on Home whenever you want to continue.

When the local project library is empty, Knit & Crochet installs one bundled tutorial project. This installation does not require membership and does not use the free personal-project allowance. If you delete it, Knit & Crochet will not recreate it repeatedly.

## Main navigation

### Home

Home is the project workspace. The header shows the current project and its next action. The project list can be filtered by states such as All, In Progress, Preparing, Completed, and Abandoned.

Pull down on Home to refresh local projects and resource relationships without making a network request, while keeping the current filters and sorting.

When Ravelry is connected, the Home header may show large free-pattern recommendations based on projects stored on this device. Swipe or wait for the next image. Tap to choose Preview Image, View Ravelry Details, or Import. The current-project card remains the fallback when Ravelry is disconnected, unavailable, or has no suitable result.

Quick Start groups destinations under Ravelry, Pattern Drafting, Project Notes, Knitting, Crochet, Yarn, Projects, Stitches, and Help. Pattern Drafting, Project Notes, Knitting, and Crochet place Files immediately after New or Import, keep supporting tools in the middle, and move the classic List to the end. Help collects the app guide, knitting chart guide, crochet chart guide, Project Notes guide, Pattern Drafting guide, knitting counter guide, swatch simulator, and feedback; the matching guide is also available inside each supported module. Modules scroll horizontally and reveal their actions in the rounded group below; the top pointer marks the active module. Select it again or use Collapse to hide the group.

Ravelry in Home’s Quick Start provides Import, Library, Pattern Search, Favorites, and Account. Pattern Search includes all patterns by default; filter by free or paid, craft, category, and language, and choose a sort order. Tap a pattern to preview it, add or remove a favorite, or view its official Ravelry details. Favorites are shared with Discover and saved in the app; they are not added to your Ravelry favorites. Direct import from search is available only for free patterns with an accessible PDF. For externally hosted content, download the file yourself and use file import. Paid patterns can be favorited and their source viewed; any purchase is completed by you on Ravelry. Purchased patterns with download access in your Library can still be imported from Library.

Advanced filters include designer name, 13 common pattern attributes (all selected attributes must match), needle/hook size in mm, multiple standard yarn weights, and a yarn amount range in meters or yards. You may enter just one bound; switching units converts an existing range. Results may cover several sizes, so check the amount for your size. Sort by currently popular, recently published, recently added, most projects, or most favorites. There is no discount filter; check prices and offers on the official page. Remove filters individually or reset them all.

The filter page keeps Apply at the top right and adds a large Apply button below Reset Filters. The heart at the top left of Discover always opens My Favorites; the More menu still opens favorites and likes. Tap Search Ravelry patterns above the favorites list to open filters, connecting your account first if needed. Apply filters, save patterns from the results, and go back to see the updated favorites. The search shortcut remains visible when favorites are empty and is hidden in the Likes segment. Pattern search menus show a short download status with Favorite/Remove Favorite first; full guidance remains in the details or import confirmation.

Knitting also offers 3D Sim and Recent 3D for simulation setup and recently successful combinations.

The Mode menu at the top right of simulation settings offers Gauge-based simulation and Structure preview. Structure preview currently covers flat stockinette, reverse stockinette, and some regular cables, using loose spacing to show loop relationships. It does not reproduce measured dimensions, estimate yarn usage, overwrite the original yarn or chart gauge, or save to Recent 3D. Charts that cannot be constructed are rejected. Verified left/right knit and purl two-stitch decreases are also supported. Three-stitch decreases are rejected. Structure preview can also attempt two-group knit/purl cables (RPC/LPC), with spacing adjusted to the actual yarn diameter. Switching modes rechecks the original selected region; failed geometry checks block the preview. Wide cable groups may use looser spacing; preview dimensions do not represent the actual gauge. Structure preview can attempt a single built-in standard 1/1, 2/2, 3/3 or 4/4 RPC/LPC on a wrong-side row while preserving the original chart’s row-side sequence. It can also attempt two adjacent 1/1 crossings, or two 1/1 crossings separated by one ordinary row. Other combinations may still be rejected by geometry checks. Selecting a chart region containing these released standard cables in the editor or simulation settings automatically selects Structure Preview. The symbol catalogue also shows their 3D preview badge.

**3D preview controls**: drag with one finger to rotate. Pinch with two fingers to zoom, or drag both fingers together to move the view; zooming and moving can be combined. If part of the fabric leaves the window after zooming or rotating, use two fingers to bring the area you want to inspect back into view. Tap Reset at the top right, or switch Front / Oblique / Back, to restore that view and center the fabric. Moving only changes the composition; it does not change yarn or stitches or rerun the simulation.

The second action at the top-left of Home opens the Wish Pool. Choose an area and a preset wish to submit it; only a custom wish requires text, and preset wishes may include an optional note. Validation and submission results appear as Toast messages. For a functional problem, use the Feedback link at the bottom and include the steps or a screenshot.

### Discover

Discover presents curated Ravelry patterns and approved community projects. Browse highlights in the banner and three featured recommendations, switch channels for more projects, and pull down to refresh. Tap an image for more photos, or open a card to view public details, favorite it, or like it. Ravelry items can open their source or be imported. Community projects can be imported as new local copies together with the photos, Project Notes, knitting charts, and crochet charts that the publisher explicitly selected. On Ravelry cards, a credit card icon at the top-right of the left-hand cover marks paid patterns, and a gift icon marks free patterns; no badge appears when availability is unknown.

Use Discover's upper-right More menu to open Favorites, Likes, and My Submissions, or choose a local project from the existing-project list to publish. The project detail More menu also provides a Publish to Discover shortcut. The editor lists public fields and shareable resources; the first selected photo becomes the cover and up to six photos can be included. A final card preview appears before submission. The publishing entry is available to everyone, while sending a project for review requires membership. It appears in a selected channel only after administrator approval. Selected content is uploaded to the public CloudKit database; counters, yarn inventory, private progress, and pattern drafts are excluded. Browsing Discover does not require Ravelry authorization; the existing connection flow is used only for Ravelry account content or Ravelry imports.

Only on Home's In Progress state tab, a project card shows a resource shortcut menu in its upper-right corner when it has linked Project Notes, pattern drafts, knitting charts, or crochet charts. The All and other state tabs do not show this shortcut. Project Notes appear as direct actions first; pattern drafts, knitting charts, and crochet charts remain grouped in collapsed submenus. Select a resource name to open it.

### Yarn

The Yarn tab is an inventory manager. Its header summarizes yarn count, known remaining weight, low stock, and records that need inventory details. Browse the library by folder, search, and inventory filters.

### Tools

Tools contains knitting charts, crochet charts, counters, Project Notes, color tools, symbol libraries, and calculators. Items created here can later be linked to a project.

### Settings

Settings contains appearance, language, membership, data sync, release notes, feedback, privacy information, this help center, and About. The Acknowledgments item in About opens the page for the current language.

## Display and navigation on iPad and iPhone Duo

iPad supports portrait and landscape. iPhone Duo keeps the phone layout on its outer display and adjusts the layout to the available space when unfolded. You can continue the current page and task when rotating, opening, or closing the device.

- Pages with top navigation: when the system shows a sidebar, the same page actions, such as Back, New, and Save, are also available at the side. Text actions may appear in the system More menu.
- Unfolded portrait with horizontal system bars: use the existing top navigation.
- Knitting, crochet, and pattern editors, along with the PDF reader, keep their own toolbars and controls.

Top and side controls follow the same saving and validation rules. Navigation on other iPhones and iPad works as before.

## Yarn library

### Create and edit records

- Choose hand-knitting yarn or cone yarn at the top of the specification card for every new or edited record. You can switch directly between them; the matching fields update without immediately erasing values entered for the other mode.
- For hand-knitting yarn, enter the number of balls or skeins, weight and length per package, and a per-package or total price. For cone yarn, enter cone count, per-cone or total weight, Nm count, ply, and price mode.
- Cone-yarn total length is calculated from total weight, Nm, and ply by default. If Nm is unavailable or the actual length differs, enter the total length directly. A manual value takes priority; clear it to restore automatic calculation.
- The specification card previews total weight, total length, and purchase total. Incomplete specifications can still be saved.
- The specification card normalizes a per-ball, per-skein, or per-cone price into a purchase total. A legacy record with only one price is marked as needing confirmation instead of being guessed. It joins confirmed purchase, consumed cost, and remaining stock value statistics only after you explicitly choose per-package or total pricing.
- Attach multiple photos and keep purchasing or usage details. In the shared yarn and project image editor, Replace All selects a new complete set; when images already exist, Add Image opens a menu to add at the end or as the first photo. The first photo is also used for the cover and color sampling.
- Yarn details opens separate editors for product details, material and fiber content, and yarn weight. You can record a brand, product line, colorway, color number, dye lot, weight category, and WPI. The color card combines Hex entry, color extraction from the first photo, and manual selection. The detail summary shows at most two product fields and only the first fiber item; long text keeps a readable size and truncates at the end. A single material with no ratio is shown explicitly as 100%, and a new component can fill the known remainder. The material page estimates fiber density from known components and ratios, with preset and custom overrides. Use the information button beside density to view the exact typical values, ranges, and calculation rules used by the app. Yarn weight is descriptive and never overwrites weight, length, or Nm count.
- Specification Analysis converts a hand-knitting yarn’s package weight and length into length per 100 g, linear density, Nm, and remaining length. For cone yarn it prioritizes a manual total length, otherwise calculating from Nm and ply; weight plus total length can also derive linear density and Nm when the count is unavailable. Yarn weight adds common needle, hook, and stockinette-gauge ranges. Fiber density is used only for a clearly labeled equivalent-solid-diameter estimate, not the real diameter including loft, twist, and air. The swatch simulator remains a separate Knitting Tool.
- Link yarn to projects. Both categories record project usage in grams for cost estimates. When total weight and total length are both available, used and remaining length are estimated proportionally for either category.
- Yarn library cards show only the name, category, primary specification, and remaining inventory. When choosing yarn for a project, the last line shows usage and estimated cost for that project.
- Swipe left on a card in the regular yarn library to move, copy, or delete it. Move opens the searchable half-sheet folder picker. After copying, use the brief Edit Copy action to continue changing the new record. Copy is also available from the detail menu, where you can edit the copy immediately. A copy keeps the full record and photos but starts as new stock without the original yarn's project links or usage. Swiping from the left edge of the detail page follows the same autosave rules as the back button.
- Use Folder in yarn details to move a record or create a folder. Folder changes follow the same autosave rules as other edits.
- Folder selection uses a searchable, scrollable half sheet, so large folder libraries remain manageable. A completely unchanged new-yarn page closes without creating an empty record.

### Find and organize yarn

- All and Uncategorized are fixed destinations and cannot be renamed or deleted. Create, rename, delete, and drag to reorder personal folders. Deleting a folder only moves its yarn to Uncategorized.
- Below search, a persistent row shows the current filter, current sort, and result count. Tap Filter for hand-knitting yarn, cone yarn, low stock, or missing inventory.
- Tap Sort, choose Name, Time, Inventory, or Price, then choose the detailed direction. Sorting supports name, creation date, modification date, known remaining stock, confirmed purchase total, and cost per 100g. Records without a confirmed price or sufficient weight stay at the end. In folder management, touch and hold a personal folder to reorder it.
- Use stock alerts to find yarn that is running low.
- Use the yarn calendar to review added and usage records.

### Swatch simulator

Open the swatch simulator from any yarn detail page. Enter stitches, rows, finished size, or gauge information to assist with gauge and target-size conversions.

## Project workspace

Project details show basic information first, then update linked resource summaries. Open Techniques to view recommendations and the symbols used in your charts; each chart's full content loads when you open it.

### Create a project

A project can store:

- Craft type, project type, status, and cover information.
- Linked yarn and usage amounts.
- One or more main counters.
- Project Notes, knitting charts, and crochet charts.
- Recommended techniques and symbols actually used by linked charts.

### Continue working

Home prioritizes recently updated projects. Project cards use a square 1:1 cover that fills the card; the title, status, and progress are grouped inside a dark gradient overlay at the bottom of the image. The layout adapts to light or dark appearance and iPad orientation. Open a project to continue its main counter or enter its materials, charts, notes, and techniques.

Below search, each status page always shows its current filters, sort, and result count. Combine knitting or crochet, project category, local or Ravelry source, due-within-seven-days or overdue schedule, and the main-tool sizes and forms actually used by projects. Each status page remembers its own choices. Sort by name, update, creation, start, target or completion date, or progress; projects missing the chosen date stay at the end.

### Project status

Projects can be Preparing, In Progress, Completed, or Abandoned. Changing status organizes the list and does not delete project content.

### Complete project package

Members can export a project together with linked yarn, counters, charts, PDFs, images, and resource relationships as one `.lineopus` file. Import creates an independent copy and does not overwrite an existing project with the same name.

<a id="counter"></a>
### Time spent

The knitting counter, project notes, knitting chart editor, and crochet chart editor each include a Timer entry. Start it manually. Dismissing the timer sheet does not stop it, while leaving the module or sending the app to the background stops and saves the session. Only one timer can run at a time; starting another ends the previous session first.

When a module is opened from a project, the session is assigned to that project automatically. A resource opened on its own keeps a resource-only history and is not assigned retroactively. In project details, Notes & Time shows the total, module breakdown, and recent sessions; swipe a session to delete an incorrect record. Completed sessions are included in `.lineopus` exports.

## Knitting counter

The counter can be used as a standalone tool or as the main progress tracker inside a project.

### Counting

- Track rows/rounds and stitches, or use a single-value counter.
- Configure fixed stitch counts or increase/decrease rules.
- Choose automatic advance, confirmation, or manual completion when a row target is reached.
- Add multiple counter tabs, then rename, reorder, or remove them.
- Use action logs for project analysis.

### Knitting plan

Save the current counting rule as a plan task and add later sections. Applying the next section changes the rule without clearing the current values, logs, or linked chart.

### Chart modes

Each counter supports three display modes:

- **Knitting chart**: link an in-app grid chart and optionally follow the current row automatically.
- **Project Notes**: link a PDF or image note in read-only mode and remember the counter's current page.
- **Text instructions**: save written steps and adjust text size.

## Smart Pattern Drafting

One finger or a pen uses the active tool; two fingers pan and pinch to zoom. Select an object before dragging. Hold overlapping objects to choose one, or use the object panel. Draw → Geometry offers saved construction points, two-tap or dragged straight lines, polylines, rectangles and center-to-edge circles. Keep paths open, continue them or explicitly close them. In Edit → Nodes, drag a selected segment’s midpoint to bend it with endpoints fixed; square handles refine curves. Brush and eraser handle sketches. Convert a single sketch through preview and confirmation into an independent piece, retaining the stroke. Connecting open paths creates a previewed continuous copy and retains originals and annotations. Continuous actions can be undone.

The groups are Draw, Edit, Annotate, Knit, Person & References, Preview, and Objects & Display. Switching groups shows a short hint. Frequent tools stay visible; related actions expand as needed. Finish, Close, Keep Open and Cancel appear only during path drawing. Annotate contains Text, Tips, leaders and dimensions; Knit contains gauge, boundaries, knitting joins, chart placement and colorwork. Grid visibility, grid/endpoint snapping and direction constraints are independent.

The active drawing tool stays highlighted. The geometry entry names the current shape, such as “Geometry: Circle”, and its menu highlights that tool too. Opening or dismissing the menu keeps the tool unchanged. Hold a tool for a short explanation. The contour pen creates editable piece outlines that you can close or keep open; the brush stores sketches and handwriting, converted into an independent piece only after preview and confirmation. Symmetry has its own on/off highlight and applies to the contour pen and polylines.

Automatic actions appear after a complete rectangle, circle, ellipse or straight line, in a fixed tool area outside the canvas while keeping the drawing tool active. Contours and polylines show actions after explicit closure or completion as an open line. Actions stay hidden during point placement, dragging and unfinished paths. Starting the next drawing hides the old actions but retains the tool-area height to prevent canvas jumps. Brush strokes and erasing do not open menus automatically. Completed text, Tips, image and dimension additions also show their actions. Explicit object selection still uses a nearby floating menu; geometry, color and snapping options open from their controls.

Double-tap is an additional editing shortcut. With an idle drawing or selection tool, double-tap a piece for stretching, scaling and layout rotation, or a sketch/image for whole-object transforms. Text/Tips open content and style; dimensions open their editor. Body references only select that part and offer position unlocking, without stretching. The canvas names the edited object and offers Done Editing, which restores the previous menu and drawing tool; choosing another tool explicitly uses that choice. Unfinished contours, dimension placement, construction points and two-point lines retain their drawing behavior. Double-tap still closes an active polyline. In selection/node/transform modes, double-tap blank space to fit the view. Unlock objects before editing. Sketch transforms preserve strokes; conversion, erasing, hit testing and export use their paper positions after rotation. Charts keep their existing gauge mapping.

The selected-object menu shows frequent actions for its type, plus Objects & Layers and More. Pieces offer transform, nodes and duplicate; text/Tips offer content and style; sketches offer conversion preview; dimensions offer editing. The object panel locates and highlights the current object. Each row’s More menu offers its available editing, rename, duplicate, stacking and delete actions, always targeting that row. Unlock an object before editing or deleting it. A body block or body reference part can be copied as an independent piece; Hide Reference preserves its human-body source. Deleting a piece removes connections but keeps text, manual dimensions and chart records with invalid-link warnings. Independent charts and other projects remain. Duplicate, delete and stacking actions support Undo during the current edit; deletion requires confirmation.

The geometry menu includes Ellipse: drag between opposite corners of its bounding rectangle to set width and height. Select a piece, then choose Edit → Transform. Drag an edge to stretch horizontally or vertically, or a corner to scale proportionally; Lock aspect ratio also constrains edge handles. The top handle rotates only the paper layout. Precise dimensions accepts width/height in cm and a layout angle; resetting the angle keeps the center and real size. Resizing changes the actual outline and recalculates stitch/row estimates when gauge is available; manual plans are retained for review. Layout rotation preserves knitting direction and plans. Anchored text and dimensions follow and remain readable; charts rotate with the piece. Body-block comparison uses actual dimensions and the original knitting direction. Pinching only zooms the view; nodes and curves remain editable. Transforms support undo, and saving restores layout angle and aspect-lock state.

Body-block front, back and sleeve parts, and each body-dimension reference piece, have separate rows in Objects & Layers. Select, unlock, move, hide and reorder them individually. Tap a part’s outline, reference line or title, unlock it and drag within its frame. Its construction lines, points and notes move together; other parts stay in place. Existing projects inherit the former group’s position, visibility and lock state. Body-data updates preserve matching part identities and adjusted positions. References remain read-only at 1:1, without stretching or node editing. Copy as Piece copies the current part directly into an editable piece. Moves support Undo and saving; use the comparison page for precise checks.

Person & References selects measurements, reference images or independent copies of body-block pieces. Changing the person does not reshape drawn pieces. Objects & Display → Objects & Layers provides selection and location, visibility, locking, drag sorting and front/back ordering. Locked objects cannot be dragged normally but remain selectable in the panel for unlocking. Paper & Display sets dark, light or custom paper, centimeter minor/major grids, stitch grids and reference styles without recoloring content. More → New Defaults affects later documents; the current document can explicitly adopt common paper defaults.

Preview → Compare with Body Block starts from the current piece. Choose a front/back block and a full or half piece. Mark its centerline and corresponding chest/waist level, then align at a chosen level and lock the reference at 1:1. One finger moves only the unlocked reference; two fingers navigate. Mark same-side neck/shoulder, shoulder tip, neck center, underarm and hem as needed. Results use actual outlines for widths, planar side differences and shoulder/neck/vertical measurements. Missing marks or multiple intervals do not produce a single width. Tap a result to highlight it. Confirm to save evidence and placement, then edit the piece and resume comparison; Back cancels changes. Rule-derived blocks may include estimates. Differences are not whole-garment ease, body clearance, pressure or a fit verdict.

Planar preview shows actual pieces and body references and preserves the editing view on return. More → Export Design independently controls grids and expanded, numbered or hidden Tips. Saves retain open paths, annotations, stacking and paper. Each document restores its viewport, tool, selection and confirmed comparison without replaying commands or restoring Undo history. Pattern Records and Files share the latest successfully saved full-design preview, independent of the last zoomed or blank viewport. Readable older documents retain identity, geometry, notes and plans; unknown data is not overwritten with a blank project. This update has not been compiled or validated on a device.

## Knitting charts

Free users can create up to 3 knitting charts. After reaching 3, creating or importing another chart requires a subscription; existing charts remain available to open and edit. The existing membership rule for large knitting canvases is unchanged.

The knitting chart editor stores colors and stitch symbols in grid cells. It is suitable for stitch charts, stranded colorwork, cross-stitch, and pixel art.

### Draw and edit

- Configure rows, columns, cell size, and reading direction.
- Choose stitches from the system or custom symbol library.
- A custom symbol can be built from symbols, text, or an image. Images support Fit Entire Image or Fill and Crop, and are orientation-normalized and compressed before saving.
- Draw symbols, fill colors, erase, undo, and redo.
- Use area selection for copy, cut, paste, fill, replace, and repeated placement.
- Save reusable colors, templates, and custom symbols.

<a id="knitting-chart-area-operations"></a>
### Area operations

Tap **Area Operations** in the bottom toolbar, then drag the selection or its four edge handles to set the range. Copy, Cut, and Paste are useful when you want to reuse the same clipboard content. Commands under **More Operations**—transforms, mirror copy, four-direction fill and repeat counts, 2D Tile, Alternating Mirror, Half-Drop Repeat, and Save as Pattern—use the current selection directly, so you do not need to copy first and your existing clipboard remains unchanged.

- **Transform**: flip horizontally or vertically, rotate 180°, or create a mirrored copy on either side. With **Mirror Stitch Symbols** enabled, directional decreases, increases, and cables are changed to their matching mirrored stitches. Neutral, custom, and unmapped stitches remain unchanged.
- **Repeat**: **Fill Left**, **Fill Right**, **Fill Up**, and **Fill Down** keep the motif orientation and repeat it to the matching canvas edge. Their repeat-count commands limit the total number of blocks in that direction, including the current selection. **2D Tile** repeats the selection to the right and down to the canvas edges. **Alternating Mirror** alternates the original and horizontally mirrored motifs across columns. **Half-Drop Repeat** shifts the 2nd, 4th, 6th, and later alternating motif columns down by half the selection height, so the selected height must be even.
- **Area editing**: **Blank Cell Stitches** affects only cells in the current selection that do not yet contain a stitch and preserves their backgrounds. With chart rules, flat knitting fills right-side rows with knit stitches and wrong-side rows with purl stitches; knitting in the round fills every row with knit stitches. You can instead choose one single-cell stitch and symbol color. Existing stitches, **No Stitch**, and cells occupied by multi-cell stitches are not replaced.
- **Drawing mirror integration**: when **Left/Right Mirror** or **Up/Down Mirror** is enabled in the editor, canvas-changing area commands—including Cut, Paste, transforms, repeats, and area edits—also synchronize their final result to the opposite side of the full canvas. The original operation wins where the two ranges overlap, and the whole command still takes one undo step. **Mirror Stitch Symbols** remains a separate option for horizontal area transforms.
- **Patterns and other projects**: **Save as Pattern** stores the selection in My Patterns for reuse on another canvas. Cross-project copy uses a separate shared clipboard. In My Patterns, touch and hold a pattern to move it to another category or delete it.
- **Edges and undo**: multi-cell stitches must be fully selected, and an incomplete stitch is not written when it cannot fit at a canvas edge. Each area command creates one undo step.

Examples:

1. Select a 4 × 4 motif and choose **2D Tile** to fill continuously from the selection’s top-left corner toward the canvas bottom-right.
2. Select a 6-row motif and choose **Half-Drop Repeat**. The 2nd, 4th, 6th, and later alternating columns are shifted down by 3 rows.
3. Select a motif with left- and right-leaning decreases or cables, enable **Mirror Stitch Symbols**, and choose **Alternating Mirror** to alternate both the motif geometry and stitch direction.
4. Select the part of a chart where blank squares represent base stitches, choose **Blank Cell Stitches**, review the rule and affected count, then fill everything in one undoable command.

### Create from an image

The image workspace has two separate paths:

- **Regular image**: for photos and illustrations. Crop, rotate, change aspect ratio and placement, then reduce the image to pixel colors.
- **Grid chart**: for pixel images or pattern images/PDFs that already contain cell lines. Calibrate the outer frame and horizontal/vertical spacing before aligning it to the editor grid. Then choose pixel drawing or symbol drawing.

Grid charts can adjust canvas cells, chart scale, and position. Preview before applying so existing canvas content is not replaced unexpectedly.

Color drawing offers **Natural**, **Simplified Blocks**, and **Monochrome** plans. A regular image can use quick preview or open **Confirm Drawing Plan** to edit settings and color groups; a grid pixel chart samples each calibrated cell before confirmation. You can recolor, locate, merge, split, or ignore groups. Symbol drawing shows grouped recognition results and lets you correct the stitch and cell background. Every path creates a preview first and changes the project only after **Apply to Canvas**.

### Counter mode and export

Link a chart to a project counter to display the current position on a larger canvas and follow rows. In the chart editor’s own counter mode, enable **Show Current Row Stitches** in common settings to display consecutive stitch runs in actual knitting order, including stitch color, cell background, and direction.

- Flat knitting reads odd rows from right to left and even rows from left to right. Knitting in the round reads every row from right to left. The project’s **Knitting Method** setting controls this behavior.
- Hiding row markers also hides the current-row strip. When column markers are enabled, the current column is the preferred position; otherwise the strip remembers its reading position.
- Adjacent cells merge only when stitch, symbol color, and background match. Blank cells break a run when their meaning is set to Ignore. **No Stitch** represents no worked stitch, so it is neither displayed nor counted and does not split matching stitches on its two sides.
- **Blank Cell Meaning** ignores blank cells by default or maps each one to any symbol already supported by the app. A chart can follow the general setting, explicitly ignore blanks, or choose its own symbol. This changes only the current-row reading and never writes symbols into the chart. Mapped stitches are labeled “Stitch Name (Blank Cells)” and counted separately from stitches drawn on the chart.

Export options include images and editable project files; use project files for continued editing and images for sharing or printing.

### Saving

- Timed autosaves are disabled while you edit so saving cannot interrupt canvas interactions. Changes are saved when the app moves to the background, when you open Export, or when you tap Close; Close waits for the save to finish before returning. The top Save button remains available for an immediate manual save.
- Saved knitting charts remember the canvas position and zoom when you leave the editor or put the app in the background, and restore that view when reopened. Panning or zooming alone is saved too. After a screen rotation or window resize, the chart point that was at the center of the previous view returns to the center of the current view. Browsing a new, unedited blank chart and closing it does not create a saved record.

## Crochet charts

Free users can create up to 3 crochet charts. After reaching 3, creating or importing another chart requires a subscription, while existing charts remain available to open and edit.

The crochet editor uses a free canvas and is not restricted to the knitting grid.

- Create a canvas and configure its background and size.
- Use the multilingual system symbol library or maintain custom symbols.
- Move, rotate, scale, copy, delete, and reorder symbols.
- Select multiple symbols for grouping and whole-group transforms.
- Arrange repeated symbols along straight or curved paths and adjust direction, spacing, and start position.
- Use quick fill, default sizing, counters, and canvas guides.
- Save and export crochet charts.

### Editing tips

- Search the symbol library by name, abbreviation, or keyword. Recently selected symbols appear first under Used.
- Project settings control the line width and default size of newly added symbols. Turning-chain symbols 2–6, as well as the hdc, dc, tr, dtr, and ttr symbols, include a curvature handle for bending. The same handle also supports hdc blo and dc blo (back loop only), plus FPhdc, BPhdc, FPdc, BPdc, FPtr, and BPtr (front/back post stitches).
- Layer management shows regular group members recursively. Expand or collapse a group, locate elements, toggle visibility, or lock them.
- In multi-select mode, tap elements to add or remove them, or draw a new selection box to replace the current selection. Drag any selected element to move the selection together without creating a group, and tap empty canvas to exit multi-select.
- Smart Snapping is on by default. The center crosshair always follows the element while dragging; its center can snap to the visible canvas center, and its visual edges or center can align with other visible elements. A successful snap shows a highlighted guide and gives one light haptic response. Turn snapping off under Settings > Editing Aids while keeping the center crosshair.
- Timed autosaves are disabled while you edit so saving cannot interrupt canvas interactions. Changes are saved when the app moves to the background, when you open Export, or when you tap Close; Close waits for the save to finish before returning. The top Save button remains available for an immediate manual save.
- Saved crochet charts remember the canvas position and zoom when you leave the editor or put the app in the background, and restore that view when reopened. Panning or zooming alone is saved too. After rotating the screen or resizing the window, the previous canvas center returns to the center of the current view. Browsing and closing a new, unedited blank chart does not create a saved record.
- Export supports PNG/PDF, resolution, margins, and background options, plus optional title, notes, symbol legend, author, and copyright information.

Knitting and crochet editors use different data and coordinate models. Create and import files with the matching editor.

<a id="crochet-area-operations"></a>
### Crochet area operations

Enter Multi-select, tap or drag to select elements, then open Area Actions. Cancel, Copy, Delete and Group remain available. The panel opens as a half-sheet on iPhone and a popover on iPad.

The bottom “Multi-Select” button and the “Area Actions” button shown after selection have visible text labels. Group uses a stacked-squares icon. Long-press a tool to see its purpose and requirements.

Horizontal and vertical flips happen in place. Mirror Copy keeps the original, creates a reflected copy just outside the corresponding edge, selects the copy, and uses one undo step for the whole operation. Stitch identities stay unchanged; text and numbers move without mirroring their glyphs so they remain readable.

On the custom symbol creation page, the mirrored copy is added to the same creation container, and the container remains selected.

**Group scope**: The second text button, “Area Actions”, in the group editing toolbar opens Area Actions directly; Ungroup remains a later action. When multiple top-level objects are selected, operations apply to the selection as a whole. When one group is selected, “Entire group” is the default: geometric operations (repeat layouts and scaling as a whole) apply to the whole group. Switch explicitly to “Group members” to align, distribute evenly, or edit the content of visible, unlocked direct members in bulk (including recoloring group stitches, replacing group stitches, and unifying group stitch size). The operation preserves the group container; unified stitch height preserves proportions and keeps each stitch center in place. A nested group is treated as one member. Editing a custom group symbol changes only the current canvas instance; it does not automatically change the library template. Copies of members stay in the current group. When editing a nested group on its own, whole-group copies stay in its original parent group, and the current group remains selected.

**Repeat layout**: Choose “Horizontal repeat” or “Vertical repeat”, then enter “Total copies (including original)” and “Pattern spacing”. The total includes the original pattern, and spacing is measured between the visible edges of two patterns. The original stays in place, while copies may use other canvas space.

**Circular / fan repeat**: Tap the canvas to set the center. The radius is calculated from the original pattern’s position and can be adjusted in the panel. When the radius changes, the first copy (the original pattern) and all copies use the new radius; if the center overlaps the pattern center, the layout starts from the right by default, and the radius is prefilled from the estimated pattern bounds. The total includes the original; 360° is a full circle with evenly distributed copies and no repeated end position. A fan includes both endpoints, with the original as the first copy. Choose clockwise or counterclockwise, then choose whether to rotate with the angle or keep the orientation.

**Size**: Scaling as a whole changes both stitch sizes and the distances between them. Unifying stitch height preserves proportions and keeps each stitch center in place.

Canceling or returning leaves the canvas unchanged; tap “Apply” to commit the operation. Each application creates at most one undo step, and an unchanged operation adds no history entry.

**Rotation and alignment**: rotate left or right by 90°, or by 180°, around the selection bounds center; positions and symbol orientations rotate together. With at least two elements, align left, horizontal center, right, top, vertical center or bottom. Bounds include rotations, curves and visible group members. Groups transform together, including their locked members.

**Spacing**: select at least three elements to make the visible horizontal or vertical gaps equal. Keep the existing span when it is sufficient; when elements overlap or the span is too small, automatically expand into other canvas space around the original selection center. Equal spacing takes priority, with no need to move the end elements manually. Positions on the other axis stay unchanged, preserving any prior alignment. Pan with two fingers to view the expanded area.

**Symbol editing**: recolor or replace crochet symbols recursively within the selection, skipping hidden or locked branches. Shapes and text outside custom symbols, and all images, are excluded from recoloring and replacement. Groups and paths retain their structure; with multiple top-level objects selected, custom symbols are replaced as atomic symbols. When one group is selected, switch to “Group members” to edit group stitches while preserving the current custom group container. Replacement preserves position, size, rotation, annotations and layer order. Built-in symbols inherit the previous color, line width and opacity; custom symbols retain the new template’s internal colors and line styles. Existing built-in curvature is retained only when the old and new curve styles are compatible.

Each actual change takes one Undo or Redo. Canceling a picker and unchanged operations add no undo step. Results are saved with the project and use the existing PNG/PDF export.

<a id="data-transfer"></a>
## Import, export, and sync

### iCloud data sync

Upload and download in Settings operates as a full-library backup. A complete backup includes `kv.db`, PDF/image assets, the separate `pattern_draft_v3.db`, `PatternDraftV2.*` settings, and user/imported pattern strategies. People, body measurements, recovery drafts, output preparation, and strategy purchase records are included in that complete package. Download replaces local data with the cloud backup; it is not a record-by-record merge. Check the device and backup time before restoring.

Backup Center also provides one Automatic Backup package per device. It is available to both free and member users and does not use the manual quota. On the first foreground activation and after each return to the foreground, the app waits about three seconds and then asks a background thread to create and validate a temporary complete package. Moving to the background only gives an already-running task the system's allowed background time; it does not start a new package there. If that time expires, the attempt is cancelled and the previous package is kept for a retry after the next foreground return. The device can complete at most one successful update per local calendar day. The local package does not require iCloud. The iCloud copy uses one shared logical slot under `AutomaticBackupV1`; an upload failure does not replace the local package or the previous cloud copy.

If an automatic backup update fails, the reason is shown and the app makes up to two more attempts during the current foreground session, about 30 seconds apart. An existing valid package remains available for rollback. Manual backups are fully validated again after being committed, before the previous package is replaced.

The Automatic Backup card shows the local save time, source device, and sync state, and provides Emergency Rollback. Rollback replaces current data and asks for confirmation first; after a successful restore, close and reopen the app. A damaged current database does not block recovery when the automatic package is valid. Automatic Backup does not represent every app setting and is not guaranteed to finish on every background transition.

### File types

- `.lineopus`: one project and its linked resources; it may include the pattern, output chain, recovery draft, and required strategy dependencies associated with that project, but not the full pattern library or purchased entitlements.

Use the same app version on both devices when using a complete V3 backup. Older app versions can read only `kv.db` and `PDFAssets/`, cannot restore Pattern Draft data, and reject V2 `.lineopus` packages.
- `.pxproj` or knitting-project formats: editable knitting charts.
- PDF/images: sources for Project Notes or sharing output.
- Yarn CSV V2: batch export creates a folder containing a version manifest, yarn table, component table, image table, and image files. Headers include both localized names and stable field IDs, so packages can be edited and imported across languages. Import validates the complete package before writing any records. Legacy `line_list.csv` files are no longer supported.

A complete project package is not a replacement for a full-library backup, and a full backup is not intended for sharing one project.

<a id="faq"></a>
## FAQ

### Why did an import create a copy?

Complete project and chart packages import as copies by default to protect existing local work.

### Why is a PDF or image missing on another device?

Make sure you used a current backup package that includes assets and allowed upload/download to finish. Copying an older database file alone may omit PDF and image files.

### Why does the tutorial not return after I delete it?

The tutorial is installed only during the first empty-library check. Deleting it means it is no longer needed, so Knit & Crochet does not recreate it.

### Why does a button open the membership page?

The action is a member feature or its free allowance has been reached. Existing content normally remains viewable or editable as described by the on-screen message.

### How should I report a problem?

Open Settings → Feedback. Include the steps, expected result, actual result, and a screenshot for visual or layout issues.
