<a id="create"></a>
## 作成

版型には新規作成、ファイル、記録、テンプレート、プリセット、ゲージ、人物があります。棒針／かぎ針を選び、自由描画、人体原型、作成方式、テンプレートから開始します。自由描画は空のグリッドを直接開き、人物やゲージは後で追加できます。どの起点も同じ編集キャンバスにつながります。作品やフォルダとの関連を維持し、ライブラリの記録は長押しして確認後に削除できます。

<a id="canvas"></a>
## キャンバス

一本指またはペンは現在のツール、二本指は移動とピンチ拡縮です。対象を選んでからドラッグします。重なった対象は長押しかオブジェクト一覧で指定します。描画→図形には保存可能な作図点、2点またはドラッグの直線、連続線、長方形、中心から描く円があります。開いた線の保存・続き描き・明示的な閉合に対応します。編集→ノードでは選択線分の中点をドラッグして端点を固定したまま曲げ、四角いハンドルで精修します。ブラシと消しゴムはスケッチ用です。一本のスケッチはプレビュー確認後に独立パーツへ変換し、元の線を残します。開いたパスの接続は元と注釈を残した連続コピーを作ります。連続操作は取り消せます。

<a id="tools"></a>
## ツール

下部は描画、編集、注釈、編み物、人物と参考、プレビュー、オブジェクトと表示に整理しました。切替時に短い説明が出ます。よく使うツールを表示し、関連操作だけを展開します。完了・閉合・開いた線を残す・取消は描画中のみ表示します。Text、Tips、引出線、寸法は注釈、ゲージ、境界、接合、図解配置、配色は編み物にあります。グリッド表示と各吸着・方向制限は別設定です。

使用中の描画ツールは選択表示が続きます。図形の入口には「図形：円」のように現在の形が表示され、メニュー内でも選択されます。開く・閉じるだけではツールは変わりません。長押しで短い説明を表示します。輪郭ペンは編集可能な衣片輪郭を作り、閉じるか開いた線として残せます。ブラシはスケッチや手書きの筆跡を保存し、プレビューして確認した後に独立した衣片へ変換できます。対称描画の有効状態は別に表示され、輪郭ペンと連続線に適用されます。

矩形・円・楕円・直線を完成すると、描画ツールを維持してキャンバス外の固定ツール領域に操作を表示します。輪郭・連続線は明示的な閉鎖または開いた線としての完了後に表示します。点の配置・ドラッグ・未完成の経路では表示しません。次の描画では前の操作だけ隠し、領域の高さを維持してキャンバスの跳ねを防ぎます。ブラシの各画や消しゴムでは自動表示しません。文字・Tips・画像・寸法の追加完了後も操作を表示します。明示的に物件を選ぶと近くに浮動メニューを表示し、図形・色・スナップは各ボタンから開きます。

ダブルタップは追加の編集ショートカットです。待機中の描画・選択ツールで衣片をダブルタップすると伸縮・拡縮・配置回転、スケッチや画像では全体変形に入ります。文字/Tipsは内容と書式、寸法は寸法編集を開きます。人体参照はその片の選択と位置ロック解除のみです。編集中の物件名と「編集を完了」を表示し、完了後は元のメニューと描画ツールに戻ります。別のツールを明示的に選ぶとその選択を使います。未完成の輪郭・寸法配置・構造点・2点直線は描画を優先し、連続線の既存経路ではダブルタップで閉じます。選択・節点・変形で空白をダブルタップすると表示を合わせます。ロックは先に解除してください。スケッチは筆跡を保持し、回転後の衣片変換・消去・当たり判定・出力は同じ配置を使います。編み図のゲージ対応は維持します。

選択した物件のメニューには種類に応じたよく使う操作と、「物件とレイヤー」「その他」を表示します。衣片は変形・節点編集・複製、文字/Tipsは内容と書式の編集、スケッチは衣片への変換プレビュー、寸法は編集が可能です。物件パネルは現在の物件を表示して強調します。各行の「その他」には編集、名前変更、複製、重なり順、削除などを表示し、必ずその行を操作します。編集・削除するにはロックを解除してください。人体原型・人体参照の一部は独立した衣片としてコピーできます。「参照を非表示」は人体の元データを保持します。衣片を削除すると接続を削除し、文字、手入力の寸法、編み図記録は関連付けの無効を表示して保持します。独立した編み図や他の作品は残ります。複製・削除・重なり順は今回の編集内で取り消せます。削除には確認が必要です。

図形メニューの楕円は、外接長方形の対角をドラッグして幅と高さを決めます。衣片を選択し、編集→変形へ進みます。辺で横・縦に伸縮し、角で等比拡大縮小します。縦横比固定を有効にすると辺でも比率を維持します。上のハンドルは用紙上の配置だけを回転します。正確な寸法ではcmの幅・高さと配置角度を入力でき、角度リセットは中心と実寸を維持します。伸縮は実際の輪郭を変更し、ゲージがあれば目・段数を再推定します。手動計画は保持して再確認を促します。配置回転は編み方向や計画を変えません。アンカー付き文字と寸法は追従して読みやすく保たれ、図案は衣片とともに回転します。人体原型比較は実寸と元の編み方向を使います。ピンチは表示倍率だけを変え、節点と曲線も引き続き編集できます。変形は取り消し可能で、保存後は配置角度と縦横比固定が復元されます。

人体原型の前身頃・後身頃・袖と、人体寸法参照の各片は「物件とレイヤー」で別々に選択、ロック解除、移動、非表示、並べ替えができます。輪郭・参照線・タイトルをタップして選択し、解除後に枠内をドラッグします。その片の構造線・点・説明が一緒に移動し、他の片は動きません。既存作品は以前のグループ位置・表示・ロックを各片に引き継ぎます。人体資料の更新でも対応する片の識別と調整済み位置を保持します。原型は1:1で輪郭は読み取り専用のままです。「衣片としてコピー」は現在の片を直接編集可能な衣片に複製します。移動は取り消し・保存でき、精密な確認は原型比較ページを使います。

<a id="context"></a>
## 注釈と寸法

上・下・左・右・直線の寸法を選び、ノードや範囲基準を順にタップして区間を作ります。cm、推定目段数、自分の計画数量を区別します。ラベルは重なりを避け、ドラッグしてもパーツは変わりません。検査画面の境界から曲線長を注記できますが、目数には直結しません。注釈では複数行Text、タップで開くTips、引出線などを追加し、文字サイズと配置を変更できます。選んだパーツの近いノードに関連付けると追従し、個別移動も可能です。削除したアンカーは無効表示になります。

<a id="counts"></a>
## 寸法と目数段数

推定は現在の実輪郭の幅、高さ、周長、面積、各段の範囲を四方向で読み取ります。再計算で作成方式を再実行して手描きを上書きしません。ゲージ未入力でもcmで作業できます。幾何推定は確定済みの編み方ではなく、開いた線や自己交差は修正が必要です。プランで作り目、総段数、左右の増減、適用可能な襟・中央休め目を編集します。形、ゲージ、方向を変えても手動の手順や数量を残し、再確認を求めます。

<a id="settings"></a>
## 再利用設定

人物と参考で測定値、画像、原型からの独立パーツを選びます。人物変更は描いた輪郭を変えません。オブジェクトと表示→オブジェクトとレイヤーで選択定位、表示、ロック、ドラッグ順序、最前面・背面を管理します。ロック中は通常ドラッグできず、一覧で解除できます。用紙と表示では深色・浅色・カスタム背景、cm主細グリッド、編み目グリッド、参考線を設定し、既存の色は変更しません。新規既定値は今後の作品用で、現在の作品へは明示的に適用します。

<a id="membership"></a>
## 無料版と会員

無料版では版型プロジェクトを同時に2件まで保持でき、削除すると枠が空きます。上限到達後も既存の版型は開く、編集する、保存する、削除することができます。自由描画、人体原型、ゆとり、ゲージ、寸法、曲線、ノード、目数段数案など、製図に必要な基本機能は無料です。

基本ドロップショルダー長袖プルオーバーは無料ストラテジーです。フィットしたセットインなどの高度なストラテジー、マイテンプレート、複数プリセット、ストラテジー作成、パッケージの読み込み・書き出しには会員登録が必要です。生成準備は無料で、棒針チャートを実際に作成するときだけ会員状態を確認します。今後のカウンター、かぎ針、糸量出力も同じルールです。

<a id="evidence"></a>
## 証拠状態

生成と連携から棒針図、平面のかぎ針図、カウンター、糸量推定へ進みます。準備一覧からゲージ、プラン、元の画面へ戻って補完し、再度開くと同じ準備を続けられます。正式な図には実行可能で確認済みのプランが必要です。自由な閉じたパーツも対応する針目・接続条件で平面かぎ針に使えます。カウンターは出典を保持します。糸量は有効な閉領域と実測スワッチを使用し、不正なパーツは先に修正します。外接長方形で代算せず、在庫も自動で減らしません。

<a id="workflow-save-export"></a>
## プレビュー・書き出し・保存

平面プレビューは実パーツと人体参考を表示し、戻ると編集画面を保持します。デザイン書出しではグリッドとTipsの展開・番号・非表示を個別設定します。保存は開いた線、注釈、重なり、用紙を保持し、作品別に視点、ツール、選択、確認済み比較を復元します。命令の再実行やUndo履歴の復元はしません。版型記録とファイルは最後に保存成功した全体プレビューを共有し、拡大部分や空白視点を表紙にしません。旧作品の識別子・形状・注釈・計画を保護し、不明データを空白で上書きしません。未コンパイル・実機未検証です。

<a id="body-block-comparison"></a>
## 原型との比較

プレビュー→原型と比較で現在のパーツを選び、前後原型と全体・半分を指定します。中線と胸・腰などの対応高さをパーツ上に指定し、高さ基準で1:1整列して参考をロックします。一本指は解除中の参考だけを動かし、二本指は画面移動です。同側の領肩点、肩端、襟中心、脇、裾を必要に応じて指定し、実輪郭の幅、左右平面差、肩襟・縦距離を確認します。複数区間や未指定点は単一幅を出しません。結果で強調表示し、確認で根拠と位置を保存、輪郭変更後も再開できます。戻ると未確定変更を破棄します。規則原型の差は服全体のゆとり、身体の隙間、圧力や着用適合の判定ではありません。

<a id="try-on-3d"></a>
## 静的3Dプレビュー

プレビュー→静的3Dプレビューに人物、組立、試着、表示、視点、調整があります。一本指で回転、二本指で移動、ピンチで拡縮します。別グループへ切り替えると2Dを続けられます。既存3Dの範囲と制限は維持します。

幅厚比、頭部、手足はテンプレート推定を含み、背肩幅と体表長は未適合です。身長がない場合は入力するか、参考値165 cmを明示的に選択してください。寸法と計測で出典、断面周囲寸法、輪郭誤差を確認できます。パーツや接合の変更で旧結果は要更新となり、生成はキャンセルできます。

静的メッシュのプレビューであり、布の伸縮、曲げ、人体衝突、フィットは未検証です。圧力やフィット点数は表示しません。今回は未コンパイルで、実機検証も未実施です。

以前の版で人体メッシュの閉鎖または向きのエラーが表示された場合は、更新後に人物詳細を開き直してプレビューを再生成してください。人物の削除や測定値の再入力は不要です。この修正は実機での確認待ちです。

<a id="piece-colorwork"></a>
## パーツの配色模様

「編み物 → パーツの配色模様」または「3D → 表示 → パーツの配色模様」で対象パーツと既存の配色編み図を選びます。裾中央を基準に目・段のゲージで反復します。単一モチーフへの切替、整数の目・段単位の移動、地色と元の各色の置換ができます。キャンバス上でも目・段単位でドラッグでき、衿ぐり・袖ぐり・パーツ外は切り取られます。1マスは常に1目×1段で、引き伸ばしません。空白・透明色のマスと単一モチーフの範囲外には地色を使います。

保存・削除は取り消し可能で、キャンセルでは確定しません。元図またはゲージを変更したら同期してください。保存時に変更を検出すると先にプレビューを更新し、再確認して保存します。2D・組立・3D・条件を満たす棒針出力は同じ取色規則を使い、編み始めの左右は番号だけを変えます。有効な目と下層の記号を保ちます。この版は色マスまたは通常の表目・裏目のみ対応し、目なし・複数マスや構造記号・半透明色は除外します。縫い目の自動柄合わせ、帯模様、配色保存、実際の渡り糸や布の物理シミュレーションは含みません。
