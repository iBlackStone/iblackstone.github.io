## Обзор

Это счетчик с памятью, специально разработанный для вязания, состоящий из двух основных компонентов:
1. **Внешний счетчик**: В основном используется для подсчета строк с помощью PDF или шаблонов на основе изображений.
2. **Внутренний счетчик**: Специально для шаблонов, созданных с помощью встроенного редактора шаблонов приложения, предлагая более богатые функции, такие как одновременный подсчет строк и стежков.

При использовании в рамках проекта по вязанию счетчик автоматически рассчитывает расход пряжи и стоимость после ввода сведений о пряже.

### Объяснение Документа

Этот документ следует за макетом пользовательского интерфейса счетчика, объясняя функции сверху вниз.

### Добавить (Создать новую вкладку)

Используйте эту функцию, чтобы добавить настраиваемую вкладку. Один проект по вязанию можно разделить на несколько вкладок, каждая из которых полностью независима, разделяя только кнопки управления в нижней части страницы. Все данные, специфичные для табуляции (количество строк/стежков, журналы, шаблоны и т. д.) остаются отдельными между вкладками.

### Область вкладок (под панелью навигации, над переключателем режима)

#### Кнопка редактирования
- Расположен в крайнем правом от панели вкладок, используется для переименования или удаления вкладок.
- **Удаление необратимо**: Все данные, связанные с вкладкой, будут удалены навсегда. Действуйте с осторожностью.

#### Область отображения шаблонов
Отображает схемы вязания в двух форматах:
- **Внутренние шаблоны**: Созданы с помощью встроенного редактора шаблонов приложения.
- **Внешние шаблоны**: Импортные изображения или PDF-файлы из фотоальбома или хранилища устройства.

##### Область Внешнего Шаблона
> Доступ через: Панель функций → Выберите кнопку «Внешний шаблон»

- **Кнопка перекрестия (вверху справа)**: Нажмите, чтобы отобразить центризованную направляющую перекрестия для навигации по сложным шаблонам.
- **Маркеры строк (левая сторона)**: Простая навигация по строкам для внешних шаблонов. Поддерживает прокрутку и нажатие; текущая строка обозначена красным текстом внизу.

##### Внутренняя область рисунка
> Доступ через: Панель функций → Выберите кнопку «Внутренний шаблон»

По сути, холст из внутреннего редактора (без элементов управления редактированием). В отличие от виртуальных маркеров строк для внешних узоров, позиционирование строк и стежков здесь точное и точное.

### Область отображения счетчика

Показывает количество строк и стежков со следующими функциями:
- Поддерживает подсчет **Стабильного режима**.
- Поддерживает подсчет **Переменный режим** (количество стежков меняется со строками).
- Постановка цели: Дисплей мигает и слегка вибрирует при достижении целевой строки, сигнализируя о завершении фазы.
- Настраиваемая начальная строка: по умолчанию строка 0, но может быть установлена на начало строки 1, чтобы приспособиться к различным привычкам подсчета.

### Переключение вкладок

Как следует из названия, выбор вкладки определяет, какой счет (строк или стежок) будет изменен. Никаких дальнейших объяснений здесь не требуется.

### Область Журнала

Записывает журналы изменений количества строк/стеков, вызванных пользовательскими операциями:
- [S] = Стабильный Режим; [C] = Переменный Режим.
- **Кнопка примечания [M] (справая сторона)**: Добавьте заметки в журналы для отслеживания ошибок.
- Регулируемый размер: область журнала по умолчанию сведена к минимуму, но может быть расширена, когда требуется подробный обзор.
- Нажмите на зарегистрированные записи с заметками, чтобы просмотреть заметки.
- [+] операции записываются черным цветом; [-] операции красным цветом.

### Область режима вязания

- **Стабильный режим**: Постоянное количество стежков в ряду (вязание в устойчивом темпе).
- **Переменный режим**: Количество стежков меняется постепенно за ряд (вязание с различной частотой стежков).

#### Стабильный Режим
После выбора «Стабильный режим» нажмите [Настройки], чтобы открыть диалоговое окно конфигурации, требующее двух параметров:
- **Максимальное количество стежков на ряд**: Количество стежков, необходимых на ряд.
- **Всего рядов для вязания**: Целевое количество рядов.

После установки на дисплее счетчика отображается:
- В верхней части дисплея: "Швы в ряду: 10 | Целевые ряды: 20"
- В нижней части дисплея: текущий режим и единица измерения для [+]/[-] кранов.
- Правая сторона дисплея: Выполнение задачи (может превышать 100%, если вязание за пределами цели, например, 30 рядов, когда цель 20).
- Дисплей мигает, и устройство слегка вибрирует при достижении цели.

#### Переменный режим
После выбора Variable Mode нажмите [Настройки], чтобы открыть специальную страницу конфигурации (из-за увеличения количества параметров).

**Конфигуратор режимов**
- Параметры конфигурации подробно описаны с инструкциями в приложении в нижней части страницы; здесь нет повторений.

После установки на дисплее счетчика отображается:
- Верхняя часть дисплея: "Уменьшить 1 стежок каждые 3 ряда | Повторите 4 раза"
- Нижняя часть дисплея: текущий режим, текущее количество повторов и единица изменения.
- Правая сторона дисплея: Прогресс задачи (может превышать 100% при вязании за пределами цели).
- Дисплей мигает, и устройство слегка вибрирует, когда необходимо заменить швы или достичь цели.

### Панель функций

Для давних пользователей: Ранее кнопки управления были разбросаны по всей странице. По мере расширения функций централизация и классификация элементов управления стала приоритетом, что привело к текущей панели функций.

#### Кнопки Первого Ряда

##### Анализ диаграммы
Создает визуальные графики на основе журналов подсчета. Для пользователей, которым нравится визуализация данных, просмотр этих диаграмм может принести чувство выполненного долга путем отслеживания процесса вязания.

При использовании в рамках проекта анализ диаграмм предлагает расширенные функции:
- Ссылки на раздел «Запись пряжи»: выберите использованную пряжу, отслеживайте расход веса и автоматически рассчитывайте затраты на основе сохраненных цен.
- Двунаправленная синхронизация данных с разделом Yarn.
- Комплексное отслеживание истории проекта с помощью связанных точек данных.
- Функция ретроспективы проекта: просмотр сведений о проекте в табличном формате.

> Раздел «Проект» - это труд любви от разработчика. Счетчик - это всего лишь один из этапов отслеживания проекта - мы рекомендуем использовать раздел "Проект" для более полезного опыта вязания.

##### Внутренний узор
Нажатие этой кнопки переключает верхнюю область отображения шаблона на внутренний шаблон с элементами управления, включая:
- **Проект импорта**: Выберите целевой шаблон (например, дизайн Fair isle). Если изначально проект не импортируется, в области отображения шаблона доступна кнопка быстрого импорта (выберите из списка проектов, полученного из раздела «Инструмент приложения»).
- **Настройки стиля**: Доступ к редактору шаблонов для настройки стилей отображения (подробности см. в объяснении редактора "Режим подсчета").
- **Центровое количество**: Управление позиционированием строк (в включено по умолчанию). При включении текущая строка остается по центру в области отображения шаблона; при отключении строки не центрируются автоматически.
- **Стежок +/-**: Ручная регулировка положения стежка (еще не связан с количеством стежков). Пожалуйста, оставьте отзыв, если вам нужна эта функция.

##### Внешний узор
Нажатие этой кнопки переключает область отображения верхнего рисунка на внешний шаблон с элементами управления, включая:
- **Паттерн импорта**: поддерживает импорт из фотоальбома или файлов iCloud. Примечание: PDF-файлы обычно обеспечивают лучшую четкость, чем изображения, но приложение использует векторную визуализацию для улучшения качества изображения.
- **Настройки ссылок**: Из-за разнообразия внешних форматов шаблонов приложение не вычисляет автоматически высоты виртуальных строк. Пользователи могут настраивать параметры привязки (включение по умолчанию). Подробные правила использования приведены во всплываюте; здесь нет повторения.

#### Кнопки зоны управления
- **Размер журнала**: Настраивает размер отображения журнала (сворачивается по умолчанию; разверните для подробного просмотра).
- **Очистить журналы**: Удаляет все журналы для текущей вкладки (необратимо). Связанные заметки и данные диаграммы также будут сброшены.
- **Сбросить количество**: Быстро сбрасывает выбранное количество (строка или стежок). Чтобы сбросить оба, выполните действие дважды. Все сбросы требуют вторичного подтверждения для защиты пользовательских данных.

### Нижние кнопки управления
- [-]: Уменьшите выбранное количество (ряд или стежок).
- [+]: Увеличьте выбранное количество (ряд или стежок).
- **Селектор единиц (средний)**: корректирует блок приращения/уменчения. Примечание: Если вы быстро прокрутите селектор единиц и нажмете [+]/[-] до окончания анимации, будет использоваться старый блок. Всегда обращайтесь к единице, отображаемой в нижней части счетчика — это единица измерения, используемая для расчетов.

### Связанные разделы

Ни один раздел в приложении не работает независимо; все они тесно интегрированы вокруг вязания. Текущий счетчик - это подфункция проектов вязания, предназначенная для помощи в подсчете во время процесса вязания.

> Некоторые функции счетчика ограничены постоянными или подписанными пользователями. Поддержание сложного, регулярно обновляемого приложения требует постоянного времени и усилий от разработчика.
