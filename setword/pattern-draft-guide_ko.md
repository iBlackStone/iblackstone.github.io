<a id="create"></a>
## 생성

자유 그리기, 전략, 내 템플릿은 모두 같은 패턴 프로젝트를 만듭니다. 기록, 프리셋, 게이지, 인물, 공통 설정도 관리할 수 있습니다. 내장 예제는 기본 조끼, 드롭숄더 긴소매 풀오버, 몸에 맞는 셋인 슬리브 풀오버입니다. 셋인 소매산은 검토가 필요한 후보입니다.

<a id="canvas"></a>
## 캔버스

검은 작업 영역과 센티미터 좌표를 사용합니다. 노드 모드에서 주황색 노드를 선택하고 직선/Bezier, 사각 제어점, 모서리/부드럽게, 경로 열기/닫기와 안전한 삭제를 사용할 수 있습니다.

인물을 선택하면 청록색 점선 인체 치수 참고로 몸 너비, 완성 옷 너비와 여유분을 비교합니다. 금색 인체 원형은 앞판·뒤판·소매의 목둘레, 어깨선, 진동, 소매산, 가슴·허리·엉덩이선, 가슴점과 센티미터 치수를 표시합니다. 인체 참고, 인체 원형, 완성 옷 조각은 따로 켜고 끌 수 있으며 옷 조각을 숨기면 원형만 확인할 수 있습니다. 누락값과 미확인 변환은 추측하지 않고 candidate/unknown으로 유지합니다.

삭제할 수 있는 여성 참고 XS–XL 다섯 프로필이 제공되며 공개 표준도 사용할 수 있습니다. 뒤 어깨너비, 가슴점 간격·높이, 팔꿈치둘레와 소매길이는 정식 원형에 사용됩니다. 각 값은 편집 가능하고 자체 출처를 유지합니다.

<a id="tools"></a>
## 도구

선택한 아래쪽 모드는 주황색 테두리로 표시되고 위쪽 작업이 바뀝니다. 개체 빠른 도구 모음은 위쪽 윤곽에서 16pt 떨어져 표시되며 공간이 부족하면 아래로 이동합니다. 모든 도구를 길게 누르면 초보자용 설명을 볼 수 있습니다. 오른쪽 위 더보기는 현재 패턴, 캔버스와 도움말, 고급 정보로 나뉘며 마지막에 패턴 삭제가 있습니다.

추가 모드에는 평면, 통, 밴드, 자유형 조각을 항상 표시하고 텍스트, 정보 핀, 참고 이미지, 안내선, 수동 치수, 설명선, 도안 영역은 위로 열리는 보조 팔레트에 모읍니다. 이미지는 카메라, 파일 또는 사진에서 선택할 수 있습니다. 기하 모드에는 노드, 노드 추가, 정확한 크기를 유지하고 선분, 노드 유형, 윤곽은 그룹 팔레트로 엽니다. 미러는 조각 모드에만 표시합니다. 팔레트 항목도 길게 눌러 설명을 볼 수 있고 바깥을 탭하면 닫힙니다. 통합 검사기에서 이름, 위치, 크기, 색상, 레이어, 잠금, 경계, 관계와 보조 요소를 관리합니다.

왼쪽 위 계획 카드는 처음에는 한 줄로 표시되며 현재 구성요소, 시작 코, 총 단수와 후보 상태를 유지합니다. 게이지 누락이나 경고도 표시됩니다. 카드를 탭해 펼치거나 접을 수 있고 선택은 기억됩니다. 전체 단별 상세 정보는 위쪽 계획 버튼에서 엽니다.

<a id="counts"></a>
## 코·단 계획

실제 게이지 두 값을 입력하면 후보를 만들 수 있습니다. 계획에서 단별 작업과 `2-1-3` 표기를 편집할 수 있습니다.

계획은 선택한 구성요소에 맞춰 표시됩니다. 몸판은 몸판 성형, 소매는 소매 늘림·줄임, 띠·통·자유형 구성요소는 자신의 시작 코, 총 단수와 양쪽 늘림·줄임만 표시합니다.

<a id="membership"></a>
## 무료 버전 및 회원

무료 버전에서는 패턴 프로젝트를 동시에 2개까지 보관할 수 있으며 삭제하면 슬롯이 비워집니다. 한도에 도달해도 기존 패턴은 계속 열고, 편집하고, 저장하고, 삭제할 수 있습니다. 자유 그리기, 인체 치수 참고, 정식 인체 원형, 여유, 게이지, 치수, 곡선, 노드, 코·단 계획 같은 필수 제도 기능은 무료입니다.

기본 드롭숄더 긴소매 풀오버는 무료 전략입니다. 몸에 맞는 셋인 슬리브와 향후 고급 전략, 내 템플릿, 여러 프리셋, 사용자 전략 작성, 전략 패키지 가져오기·내보내기는 회원 기능입니다. 생성 준비는 무료이며, 향후 카운터 작업, 대바늘 도안, 코바늘 도안 또는 실 사용량 예상을 실제로 만들 때 회원 상태를 확인합니다.

<a id="evidence"></a>
## 근거 상태

`confirmed`는 명확한 근거, `candidate`는 검토 필요, `unknown`은 지식 부족입니다. 생성 및 연결에서 카운터 작업, 대바늘 도안, 코바늘 도안, 실 사용량 예상을 선택할 수 있습니다. 각 항목은 생성 준비에서 원본 패턴, 대상 프로젝트, 준비 상태를 표시합니다. 프로젝트 안에서 연 패턴은 해당 프로젝트를 사용하고, 독립적으로 연 경우 직접 선택합니다. 초록색은 사용 가능, 주황색은 확인 필요, 빨간색은 필수입니다. 현재 버전은 준비 플랜만 저장하며 대상 데이터는 아직 만들지 않습니다.
