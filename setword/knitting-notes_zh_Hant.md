## 創建與打開專案

1. 進入工具頁，選擇“編織筆記”。
2. 選擇要導入的 PDF 文件。
3. 導入完成後，專案會出現在編織筆記專案列表中。
4. 點擊專案即可繼續上次的閱讀位置和編輯狀態。

免費用戶最多創建 1 個編織筆記專案。刪除專案屬於不可撤銷操作，請確認不再需要後再刪除。

## 編輯器界面

### 頂部工具欄

- **關閉**：返回專案列表並保存當前閱讀狀態。
- **撤銷**：撤銷最近一次支援的畫筆或組件操作。
- **重做**：恢復剛剛撤銷的操作。
- **使用說明**：點擊 `?` 隨時打開本頁幫助。
- **更多**：重命名、保存或刪除當前專案。

### 顯示與隱藏工具欄

點擊 PDF 空白區域可以收起頂部和底部工具欄，獲得更大的閱讀區域。工具欄收起後，可點擊螢幕邊緣的小按鈕重新顯示。

使用暗黑主題時，PDF 閱讀區域預設降低白底亮度；頂部和底部工具欄仍保持黑色，PDF 原始顏色不會反轉。如需查看原始亮度，可在右上角“更多”菜單關閉“降低 PDF 亮度”。

### 基本閱讀手勢

- 單指滑動：瀏覽 PDF。
- 雙指捏合：縮放頁面。
- 點擊頁面組件：選中組件並顯示懸浮控制欄。
- 滑動或縮放 PDF：當前組件會失去焦點，方便繼續閱讀。

## 底部工具欄

| 工具 | 作用 |
|---|---|
| 頁面 | 展開頁面縮略圖和頁面標籤，快速跳轉 |
| 組件 | 選擇圖片、提示按鈕、圖解連結、文本或尺子 |
| 移動 | 返回 PDF 閱讀、滑動和縮放模式 |
| 畫筆 | 選擇畫筆並在當前 PDF 頁面繪制 |
| 橡皮擦 | 擦除畫筆繪制的軌跡 |
| 計數器 | 展開或收起專案計數器 |
| 計時 | 手動記錄本次投入時間 |
| 更多 | 打開元素管理、預設顏色、畫筆管理和尺子組件管理 |

## 頁面與標籤

點擊底部“頁面”按鈕可以打開縮略圖欄：

- 點擊縮略圖跳轉到對應頁面。
- 頂部標籤列表可以直接跳轉到已標記頁面。
- 縮略圖底部會顯示該頁標籤。
- 點擊選中縮略圖上的 `...`，可以新增、編輯或刪除頁面標籤。
- 每個頁面最多設定 1 個標籤。

免費用戶最多創建 2 個頁面標籤，已有標籤仍可編輯或刪除。

## 添加頁面組件

1. 點擊底部“組件”按鈕。
2. 選擇需要的組件。
3. 組件按鈕會顯示為選中狀態。
4. 點擊 PDF 頁面中的目標位置，組件將以觸點為中心添加。
5. 添加完成後，編輯器會自動回到移動模式。

新增頁面組件為會員功能。已有組件仍可查看和編輯。

### 支援的組件

#### 尺子

尺子可用於跟蹤當前閱讀行或列。預設提供橫向尺子、縱向尺子和 45° 尺子，並可在尺子組件管理中調整預設。

#### 文本

文本組件支援多行內容。拉伸文本框後，可以顯示更多文字。文本設定支援文字顏色、字號、對齊、複製和粘貼。

#### 圖片

圖片可以來自相機、文件或相冊。圖片按原始寬高比添加，只支援等比縮放和旋轉，不支援四邊獨立拉伸。

#### 提示按鈕

提示按鈕在頁面上顯示為固定大小的 `i` 圖標。點擊圖標可查看提示內容，雙擊彈層中的文字區域可開始編輯。

#### 圖解連結

圖解連結用於關聯 App 內已有的棒針圖解。關聯後可以顯示圖解縮略圖，並從 PDF 頁面直接跳轉到對應棒針圖解。

#### 圖解分隔組件

圖解分隔組件用於把 PDF 中已有的像素圖或棒針圖解變成帶行列資訊的可復用網格來源。

1. 從“組件”中選擇“圖解分隔框”，再點擊圖解區域放置外框。
2. 拖動外框內部空白區域調整覆蓋範圍，使用外框交互點調整大小或角度。
3. 水平輔助尺預設貼頂部，垂直輔助尺預設貼左側。分別調整輔助尺的位置和寬高，使其兩條邊與相鄰網格線重合。
4. 點擊“對齊”可將兩個方向歸正到最近的完整週期。接近精確位置時也會自動吸附並提供觸覺反饋。
5. 紅色狀態表示仍需調整；外框與網格經過確認後會顯示綠色“已對齊”。外框再次移動、縮放或旋轉後需要重新對齊。
6. “鎖定外框”只固定外框，內部輔助尺仍可調整；後置的“鎖定”會鎖住整個組件。
7. “預覽網格圖”用於檢查分隔結果，不會立即創建棒針作品。
8. “創建計數圖解”會建立並綁定一個棒針圖解。之後入口會變為“打開”或“同步”，始終復用同一個作品，不會每次創建副本。
9. “更多”可以切換校准帶/完整網格，並設定行列閱讀方向。未選中組件時仍會顯示輕量網格標記；已綁定圖解可雙擊直接打開。

進入棒針工具後可在“像素圖”和“符號繪制”之間切換：像素圖會按校准後的單元格提取底色，並在“繪制方案確認”中調整、合併、拆分或忽略顏色分類；符號繪制會逐格歸類圖形，並在“符號識別確認”中核對原圖、針法和單元格背景色。PDF 圖例文字和已經確認過的符號會作為識別線索，用戶修正也會被記憶。兩種方式都只先生成臨時預覽，確認無誤後仍需點擊“應用到畫布”。使用前請先確認四邊、行列和閱讀方向正確。

## 編輯頁面組件

點擊組件後會出現虛線選中框、交互點和底部懸浮控制欄。根據組件類型，可以進行以下操作：

- 拖動組件內部：移動位置。
- 拖動邊緣交互點：改變寬度或高度。
- 拖動右上角交互點：等比縮放。
- 拖動頂部交互點：旋轉。
- 顏色：修改組件顏色。
- 透明度：調整組件背景透明度。
- 變換：快速設定角度或縮放比例。
- 刪除：刪除當前組件。

並非所有組件都支援全部操作。例如圖片不能獨立拉伸四邊，提示按鈕和圖解連結不支援旋轉或縮放。

### 鎖定與解鎖

- 鎖定後，懸浮控制欄只顯示“解鎖”按鈕。
- 鎖定的尺子仍可整體拖動，但不能拉伸、縮放、旋轉或修改樣式。
- 圖解分隔框的“鎖定外框”只防止外框誤移動，內部輔助尺仍可調整；使用普通“鎖定”才會固定整個組件。
- 鎖定的文本、圖片、提示按鈕和圖解連結等其他組件不能移動或編輯。
- 點擊“解鎖”後，完整控制欄和交互點會重新出現。

## 畫筆與橡皮擦

點擊“畫筆”選擇預設畫筆後，即可在當前頁面繪制。

- 畫筆預設包含形狀、粗細、顏色和透明度。
- 可以在畫筆管理中新增、編輯、刪除和排序畫筆。
- 編輯器優先顯示排序靠前的畫筆。
- 橡皮擦只擦除畫筆軌跡，不會刪除尺子、文本、圖片或其他組件。
- 頁面組件請通過選中後的刪除按鈕，或元素管理進行刪除。

新增畫筆預設為會員功能，預設畫筆和已有畫筆仍可使用。

## 投入時間

底部“計時”與行數“計數器”互不影響。手動開始後，關閉計時面板仍會繼續；離開編織筆記或 App 進入後台時自動停止並保存。從作品進入的筆記會把記錄歸入該作品，獨立打開時只保留筆記自身記錄。

## 計數器

每個編織筆記專案至少包含 1 個計數器。

- 點擊數字：計數加 1。
- 點擊 `-`：計數減 1。
- 點擊清零：將計數恢復為 0。
- 點擊 `...` 或長按計數器：打開計數器菜單。
- 菜單支援編輯、快捷輸入數字、改色、重命名和刪除。
- “行數”是計數器最大值，超過最大值後會從 0 重新開始。
- 專案的第一個計數器不能刪除。

每個橫向頁面最多展示 3 個計數器。超過 3 個時可左右滑動切換，頂部頁碼指示器會提示當前頁。右上角按鈕可以切換完整和緊湊高度。

免費用戶最多使用 3 個計數器。

## 元素管理

通過底部“更多”進入“元素管理”，可以集中查看當前專案中的組件和畫筆筆記。

- 左側預覽用於識別元素內容和大致輪廓。
- 點擊元素可定位到對應頁面和位置。
- 可以鎖定或解鎖組件。
- 可以刪除不再需要的元素。
- 相鄰的畫筆軌跡會組合為較完整的筆記預覽，便於識別。

## 預設顏色、畫筆和尺子預設

底部“更多”提供以下通用設定：

- **預設顏色**：影響之後新增的頁面組件。
- **畫筆管理**：管理所有編織筆記專案共用的畫筆預設。
- **尺子組件管理**：管理所有編織筆記專案共用的尺子預設。

修改通用預設不會自動改變已經添加到專案中的組件或軌跡。

## 保存、撤銷與恢復

- 閱讀頁、頁面標籤、計數器和大部分編輯操作會隨專案保存。
- 需要立即確認保存時，可使用頂部“更多 > 保存”。
- 撤銷與重做適用於當前編輯會話中支援的組件和畫筆操作。
- 退出專案再重新進入後，撤銷棧可能不會保留，但已保存的頁面內容會恢復。

## iCloud 與多設備

編織筆記的資料備份包含專案資料庫、PDF 文件和 PDF 相關圖片資產。啓用並完成 App 的 iCloud 資料同步或恢復後，另一台設備才能看到完整專案。

請注意：

- iCloud 備份不是多人實時協作。
- 大型 PDF 的上傳和恢復可能需要更多時間。
- 恢復完成前請不要刪除原設備上的專案或 PDF 文件。
- 舊版本僅包含資料庫的備份可能無法恢復 PDF 本體。

## 常見問題

### 為什麼選中組件後 PDF 不能滑動？

組件命中區域的手勢優先級高於 PDF。點擊空白區域、切換到移動模式，或開始縮放 PDF，即可退出組件焦點。

### 為什麼橡皮擦不能刪除尺子或文本？

橡皮擦只處理畫筆軌跡。其他組件需要使用組件控制欄中的刪除按鈕，或在元素管理中刪除。

### 為什麼鎖定後的尺子還能移動？

尺子需要在閱讀過程中持續調整位置，因此鎖定只固定它的尺寸、角度和樣式。其他組件鎖定後會完全固定。

### 為什麼新增組件後需要再點擊頁面？

組件採用“先選擇、再落點”的方式，避免自動添加在頁面中心後還要手動移動。

### 為什麼有些功能會顯示會員提示？

免費版保留基礎導入、閱讀和有限額度。新增頁面組件、增加畫筆預設等高級能力需要會員權限。
